Guess the Coin Flip

So far your programs have talked, but they have not listened. In this lesson you will write your first real game. The program asks the player to guess heads or tails, flips the coin, and tells the player whether they guessed right.

To build it you will learn how to get input from the player, how to repeat something until the player gets it right, and how to make a decision.

Topics covered in this lesson

  • Getting input with input()
  • The upper() string method
  • while loops
  • The not in operator
  • Getting one character of a string by its index
  • Comparing values with ==
  • if and else statements

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

How to Play

The program asks you to type H for heads or T for tails. It flips the coin, plays a sound, and says which side landed up. If you guessed that side, you win.

Sample Run

What you type is shown right after the prompt. Because the prompt does not end with a space, your typing runs into the word Tails. Here the player types x by mistake, and the program asks again:

Enter (H)eads, (T)ailsx
Enter (H)eads, (T)ailsh
Heads up!
You guessed the toss! Congradulations!

And here is a game the player loses:

Enter (H)eads, (T)ailst
Heads up!
You did not guess the toss. Better luck next time.

The Source Code for Guess Flip

Type this program and save it as guess_flip.py in the same folder as sound_flip.py, so it can find the sounds folder:

"""Simple guess the coin toss"""
import random
import playsound as ps


guess = ""
while guess not in ["H", "T"]:
    guess = input("Enter (H)eads, (T)ails")
    guess = guess.upper()

ps.playsound("sounds/flip.wav")
coin = random.choice(["Head", "Tail"])
print(f"{coin}s up!")

if guess.upper() == coin[0]:
    print("You guessed the toss! Congradulations!")
else:
    print("You did not guess the toss. Better luck next time.")

The Plan

Before looking at each line, here is what the program does, in order:

  1. Ask the player for a guess.
  2. If the guess is not H or T, go back to step 1.
  3. Play the flip sound.
  4. Pick Head or Tail at random and say it.
  5. If the guess matches, say the player won. Otherwise, say they lost.

Writing a plan like this before you code is a good habit. Each step turns into a few lines of Python.

Getting Input from the Player

The input() function lets the player type something:

guess = input("Enter (H)eads, (T)ails")

input() prints its argument as a prompt, then waits. The player types an answer and presses Enter. input() returns what they typed, as a string, and the program stores it in the guess variable.

Try it in the shell:

>>> answer = input("What is your name? ")
What is your name? Lee
>>> answer
'Lee'

Prompts the Player Can Hear

Notice the space at the end of "What is your name? ". Without it, the player’s typing runs right up against the prompt. The prompt in this game, "Enter (H)eads, (T)ails", has no space at the end, so when the player types h the line reads Enter (H)eads, (T)ailsh. A screen reader may read that as one strange word. One of the exercises asks you to fix it.

A good prompt tells the player exactly what to type. The parentheses around H and T are a common way to show which letter to press. Your screen reader will say “left paren H right paren eds” if punctuation is on, which is a bit awkward. A prompt such as Type H for heads or T for tails: is clearer by ear.

Making the Guess Uppercase

The next line changes the guess to capital letters:

guess = guess.upper()

upper() is a method. A method is a function that belongs to a value. You call it by typing the value, a period, and the method name. Every string has an upper() method. It returns a copy of the string with all letters made uppercase.

>>> "h".upper()
'H'
>>> "Heads".upper()
'HEADS'
>>> "T".upper()
'T'

Notice that the line puts the result back into guess. upper() does not change the string it belongs to. It makes a new one. If you want to keep the new one, you must store it.

Why make the guess uppercase? So the player can type either h or H. The rest of the program only has to check for capital letters.

Asking Until the Answer Is Good

What if the player types x, or heads, or just presses Enter? The program needs a good answer before it can go on. So it keeps asking until it gets one. Here is the code that does that:

guess = ""
while guess not in ["H", "T"]:
    guess = input("Enter (H)eads, (T)ails")
    guess = guess.upper()

while Loops

A while loop repeats a block of code as long as a condition is true. The condition is the part between while and the colon. The block is the indented lines under it.

Each time the loop starts over, Python checks the condition. If the condition is true, it runs the block again. If it is false, it skips past the block and goes on with the rest of the program. Each trip through the block is called an iteration.

Listen for the indentation. The two lines under while are indented four spaces. That is how Python knows they belong to the loop. The blank lines and the ps.playsound() line after them are back at zero indentation, so they are not part of the loop. They run after the loop is finished.

The in and not in Operators

The condition is guess not in ["H", "T"]. The in operator checks whether a value is one of the items in a list. not in checks whether it is not one of them. Each gives you True or False.

>>> "H" in ["H", "T"]
True
>>> "X" in ["H", "T"]
False
>>> "X" not in ["H", "T"]
True

True and False are special values called Booleans. They are not strings, so they do not have quotes. Note the capital T and F.

So the loop means: while the guess is not H and not T, ask again.

Why guess Starts Empty

Look at the line just before the loop:

guess = ""

Two quotes with nothing between them make an empty string. The loop checks guess the very first time, before the player has typed anything. If guess did not exist yet, Python would give an error. So the program puts an empty string in guess. An empty string is not H or T, so the loop runs at least once.

Flipping the Coin

After the loop, the program plays the sound and flips the coin:

ps.playsound("sounds/flip.wav")
coin = random.choice(["Head", "Tail"])
print(f"{coin}s up!")

This time the result is stored in a variable named coin, because the program needs it twice: once to print and once to compare with the guess.

The list is written right inside the call to random.choice(), instead of being stored in a variable first. Both ways work.

The f-string adds an s after the coin, so Head becomes Heads up! and Tail becomes Tails up!.

Getting One Character by Index

The guess is one letter, H or T. The coin is a whole word, Head or Tail. To compare them, the program needs just the first letter of the coin. It gets it like this:

coin[0]

Every character in a string has a number, called its index, that tells where it is. The first character’s index is 0, not 1. The second is 1, and so on. To get a character, put its index in square brackets after the string.

>>> coin = "Tail"
>>> coin[0]
'T'
>>> coin[1]
'a'
>>> coin[3]
'l'

Counting from zero takes some getting used to. Almost every programming language does it, so it is worth learning now.

Making a Decision with if and else

The end of the program decides who won:

if guess.upper() == coin[0]:
    print("You guessed the toss! Congradulations!")
else:
    print("You did not guess the toss. Better luck next time.")

Comparing with ==

Two equal signs, ==, ask the question “are these the same?” The answer is True or False.

>>> "H" == "H"
True
>>> "H" == "T"
False
>>> "h" == "H"
False

Be careful not to mix up = and ==. One equal sign puts a value in a variable. Two equal signs compare. When you hear “equals equals” from your screen reader, think “is the same as.”

The last example shows why the program uses upper(). Uppercase and lowercase letters are different characters, so "h" is not equal to "H". The program already made the guess uppercase inside the loop, so calling upper() again here is not needed, but it does no harm.

if and else

An if statement runs its block only when its condition is True. An else statement right after it runs its own block only when the condition is False. Exactly one of the two blocks runs, never both.

Listen for the indentation again. The if and else lines are at the same level, and each has one indented print() line under it.

Summary

This was your first real game. You learned that:

  • input() shows a prompt and returns what the player types, as a string.
  • upper() is a string method that returns an uppercase copy of the string.
  • A while loop repeats its block as long as its condition is True.
  • in and not in check whether a value is in a list.
  • True and False are Boolean values.
  • A string’s first character is at index 0.
  • == compares two values. = stores a value.
  • if runs a block when a condition is True. else runs a block when it is False.
