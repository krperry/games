Flipping a Coin

Games need surprises. If a game did the same thing every time, it would not be much fun to play. In this lesson you will write a program that flips a coin. Each time you run it, you will hear either Head or tail, and you will not know which until it happens.

To do this you will use a module, which is a collection of ready-made code, and a list, which holds more than one value.

Topics covered in this lesson

  • Importing a module with import
  • The random module
  • Lists
  • random.choice()
  • Calling a function inside an f-string

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

Sample Runs

The program prints one word. Here is what it might say if you run it three times:

Head
tail
Head

The Source Code for Flip

Type this program and save it as flip.py:

"""Simplest coin flip"""
import random

coin = ["Head", "tail"]
print(f"{random.choice(coin)}")

Run it several times with python flip.py. Listen to how the answer changes.

Importing a Module

The second line of the program is:

import random

Python comes with many extra tools, but it does not load all of them every time a program starts. That would be slow. Instead, the tools are grouped into modules, and your program asks for the ones it needs. Asking for a module is called importing it.

The random module has functions for picking things by chance. After the import random line, your program can use any of them by typing random, a period, and the function’s name.

Put your import lines at the top of the program, right after the docstring. That way anyone reading your code knows right away which modules it uses.

Lists

The next line makes a list:

coin = ["Head", "tail"]

A list is a value that holds other values, in order. You make a list with square brackets, [ and ], and you put commas between the items. This list holds two strings, "Head" and "tail". The list is stored in a variable named coin.

When you read a list with a screen reader, listen for the commas. Each comma separates one item from the next. A missing comma is a common mistake that can be hard to hear.

Try lists in the interactive shell:

>>> coin = ["Head", "tail"]
>>> coin
['Head', 'tail']
>>> colors = ["red", "green", "blue"]
>>> colors
['red', 'green', 'blue']

Picking a Random Item

The last line does all the work:

print(f"{random.choice(coin)}")

random.choice() is a function from the random module. You give it a list, and it gives you back one item from the list, picked at random. Each item has the same chance of being picked. With two items, that is a fifty-fifty chance, just like a real coin.

When a function gives you a value back, we say it returns that value. Here, random.choice(coin) returns either "Head" or "tail".

Try it in the shell a few times:

>>> import random
>>> random.choice(["Head", "tail"])
'tail'
>>> random.choice(["Head", "tail"])
'tail'
>>> random.choice(["Head", "tail"])
'Head'

Your answers will probably be different. That is the point.

Functions Inside f-strings

In the last lesson you put a variable inside the curly braces of an f-string. You can also put a function call there. Python calls the function and puts whatever it returns into the string.

In this program, the f-string holds nothing else, so these two lines would print the same thing:

print(f"{random.choice(coin)}")
print(random.choice(coin))

The f-string becomes more useful when you add words around the braces, such as print(f"The coin landed on {random.choice(coin)}."). Try that in the exercises.

Designing for the Ear

Listen to the two answers again: Head and tail. One starts with a capital letter and one does not. Most screen readers say them the same way, so you might not notice. But if your screen reader is set to announce capital letters, or if someone reads the output in braille, the difference stands out. It is also a little odd that it says Head and not Heads.

When you write output for people to hear, make it clear, complete, and consistent. A short sentence such as The coin landed on heads. is easier to understand than one word, especially if the person was not paying attention when the program started.

Summary

You wrote a program that does something different each time it runs. You learned that:

  • import loads a module so your program can use its functions.
  • The random module has functions for picking things by chance.
  • A list holds several values in order, inside square brackets, separated by commas.
  • random.choice() returns one item from a list, picked at random.
  • You can call a function inside the curly braces of an f-string.
