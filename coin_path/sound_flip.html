Adding Sound to the Coin Flip

Your coin flip program works, but it is a little plain. A real coin makes a sound when you flip it. In this lesson you will play a sound file before you announce the result.

Sound is very useful in games for people who are blind or have low vision. A sound can tell the player that something happened, faster than words can. It also makes a game feel alive.

To play the sound you will install and use a module that does not come with Python.

Topics covered in this lesson

  • Installing a module with pip
  • Importing a module with a shorter name using as
  • Playing a sound file with playsound
  • File paths and folders

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

When you run the program, you hear the sound of a coin being flipped. When the sound finishes, you hear either:

Getting Ready

Installing playsound

The random module you used in the last lesson comes with Python. The playsound module does not. You need to install it once before you can use it.

Python comes with a tool called pip that downloads and installs modules. At the command prompt, type:

pip install playsound

You will hear some messages as it downloads and installs. If the last message says it was successfully installed, you are ready.

If pip is not found, try py -m pip install playsound on Windows or python3 -m pip install playsound on a Mac or Linux. If the newest version of playsound gives you errors, many people have good luck with an older version: pip install playsound==1.2.2.

The Sound File

The program plays a file named flip.wav that is in a folder named sounds. Your folders should look like this:

  • coin_path folder
    • sound_flip.py
    • sounds folder
      • flip.wav

The sounds folder must be inside the same folder as your program, and you must run the program from that folder.

The Source Code for Sound Flip

Type this program and save it as sound_flip.py:

import random
import playsound as ps

ps.playsound("sounds/flip.wav")
coin = ["Head", "tail"]
print(f"{random.choice(coin)}")

This is the same as flip.py with two new lines: one to import the module and one to play the sound. It does not have a docstring. Adding one is the first exercise.

Importing with a Short Name

The second line imports the sound module:

import playsound as ps

The word as gives the module a nickname. From here on, the program can type ps instead of playsound. Programmers do this to save typing when they use a module a lot. It is your choice whether to use as. These two programs do the same thing:

import playsound
playsound.playsound("sounds/flip.wav")
import playsound as ps
ps.playsound("sounds/flip.wav")

Notice that the module and the function inside it are both named playsound. That is why playsound.playsound repeats itself. The nickname makes it shorter.

Playing the Sound

This line plays the sound:

ps.playsound("sounds/flip.wav")

The argument is a string that tells playsound() where to find the sound file. A string that names a file and the folders it is in is called a path. This path says: go into the sounds folder, and find the file flip.wav. The forward slash, /, separates a folder name from the name of what is inside it. Python understands forward slashes on Windows, Mac, and Linux.

The path is relative. That means it starts from the folder you are in when you run the program. If you run the program from a different folder, Python looks for a sounds folder there instead, does not find it, and gives you an error. If you hear an error about a file that cannot be found, check which folder you are in.

Waiting for the Sound

playsound() does not return until the sound has finished playing. So the program plays the whole flip sound first, and only then moves to the next line and prints the result. This is the order you want. The player hears the coin in the air, and then hears how it landed.

Try moving the ps.playsound() line to the end of the program, after the print() line. Run it. Which order sounds better?

Designing for the Ear

Sounds and speech can get in each other’s way. If a sound plays while a screen reader is talking, the player might miss some words. Because playsound() waits until the sound is done, the result is spoken after the sound, not on top of it.

Keep sounds short, and use the same sound for the same event every time. Players quickly learn what each sound means.

Summary

You added sound to a program. You learned that:

  • pip install downloads and installs modules that do not come with Python.
  • import module as nickname lets you use a shorter name for a module.
  • playsound() plays a sound file and waits until it is done.
  • A path is a string that says where a file is. A relative path starts from the folder you run the program in.
