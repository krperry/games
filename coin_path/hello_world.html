Your First Program: Hello World

Almost every programmer’s first program does one thing: it makes the computer say hello. In this lesson you will write that program, save it, and run it. It is only one line long, but it teaches you the steps you will use for every program you ever write.

Topics covered in this lesson

  • What a program is
  • Making a file for your program
  • Running a program from the command line
  • The print() function
  • Strings
  • Reading error messages

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

What Is a Program?

A program is a list of instructions for the computer. You write the instructions in a language the computer understands. In these lessons that language is Python.

The computer follows your instructions exactly, in order, from the top of the file to the bottom. It does not guess what you meant. If you spell something wrong, it will not fix it for you. That can feel strict at first, but it also means the computer always does exactly what you told it to.

The Source Code for Hello World

Here is the whole program:

print("Hellow World!")

That is all. One line. Open your code editor, make a new file, and type that line. Save the file as hello_world.py. The .py at the end of the name tells the computer that this is a Python program.

Running the Program

Open a command prompt or terminal and go to the folder where you saved the file. Then type this and press Enter:

python hello_world.py

You should hear your screen reader read:

Hellow World!

Congratulations. You just wrote and ran a program.

If you hear an error that says Python was not found, Python might not be installed, or it might use a different name on your computer. On Windows, try py hello_world.py. On a Mac or Linux, try python3 hello_world.py.

How the Program Works

The program has one instruction:

print("Hellow World!")

Let’s take it apart piece by piece.

The print() Function

print is the name of a function. A function is a small, ready-made program with a name. When you use the name, Python runs that small program. Using a function is called calling it.

The print() function shows text on the screen. Because a screen reader reads what is on the screen, print() is also how your program talks out loud to the person using it.

To call a function, you type its name followed by a pair of parentheses. Inside the parentheses you put the thing you want the function to work on. This is called the argument. Here the argument is the text "Hellow World!".

Strings

Text in a program is called a string. You make a string by putting quotation marks around the text. Python needs the quotes so it can tell your text apart from its own instructions.

The quotes are not printed. Only the letters between them are. Notice that the output was Hellow World! and not "Hellow World!".

You can use double quotes or single quotes. These two lines do the same thing:

print("Hello World!")
print('Hello World!')

Just make sure each string starts and ends with the same kind of quote.

Python Prints Exactly What You Type

Did you notice that the program says Hellow with a W at the end? That is a typo in the program. Python does not know English, so it cannot tell that Hellow is misspelled. It prints exactly the letters inside the string.

This is your first lesson about computers: they do what you say, not what you mean. Go ahead and fix the typo. Change Hellow to Hello, save the file, and run it again.

Trying Python in the Interactive Shell

Python also has an interactive shell. In the shell you type one instruction at a time and hear the answer right away. It is a great place to experiment.

To start the shell, type python at the command prompt with no file name and press Enter. You will hear some version information and then the prompt, >>>. Try this:

>>> print("Hello World!")
Hello World!
>>> print("My name is Sam.")
My name is Sam.

When you are done, type exit() and press Enter to leave the shell.

When Something Goes Wrong

Everyone makes mistakes when they type code. Python tells you about a mistake with an error message. Error messages can sound scary, but they are there to help. Try making some mistakes on purpose in the shell so you know what they sound like.

Leave off the closing quote:

>>> print("Hello World!)
  File "<stdin>", line 1
    print("Hello World!)
          ^
SyntaxError: unterminated string literal (detected at line 1)

The important part is the last line. It says SyntaxError, which means Python could not understand how the line was written, and then it says what is wrong: the string was never ended. The line with the caret, ^, points to where the problem starts. With a screen reader it is often easier to just read the last line of the error and then look at your code.

Now spell print with a capital P:

>>> Print("Hello World!")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'Print' is not defined. Did you mean: 'print'?

Python cares about capital letters. Print and print are two different names, and Python only knows print. Python even suggests the fix.

When you get an error while running a file, Python tells you the line number. Go to that line in your editor and compare it carefully with the lesson.

Summary

You wrote, saved, and ran your first Python program. You learned that:

  • A program is a list of instructions that the computer follows in order.
  • Python programs are saved in files that end in .py.
  • You run a program by typing python and the file name at the command prompt.
  • print() is a function that shows text, which your screen reader then reads.
  • Text in quotes is called a string.
  • Python prints exactly what is in the string, typos and all.
  • Error messages tell you what went wrong. Read the last line first.

Exercises

  1. Fix the typo so the program says Hello World!.
  2. Change the program so it says hello to you by name, such as Hello Maria!.
  3. Add a second print() line under the first one that says something else, such as I am learning Python. Run the program. Which line is spoken first?
  4. Use single quotes instead of double quotes in your print() line. Does anything change when you run it?
  5. Remove the closing parenthesis from the print() line and run the program. Listen to the error message. What line does Python say the problem is on? Put the parenthesis back.
