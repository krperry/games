Rolling a Die

In the coin lessons you picked a random item from a list. That works well when there are only a few choices. A die has six sides, and some games use dice with ten, twenty, or even a hundred sides. Typing every number into a list would get old fast.

In this lesson you will roll a six-sided die with a function that picks a random number instead of a random list item.

Topics covered in this lesson

  • Integers
  • random.randint()
  • Passing more than one argument to a function

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

Sample Runs

The program prints one number from 1 to 6. Three runs might sound like this:

4
1
6

The Source Code for Roll

Type this program and save it as roll.py:

import random

print(f"{random.randint(1,6)}")

Run it a few times with python roll.py.

Numbers in Python

So far, every value you have worked with has been a string or a list of strings. Python can also work with numbers. A whole number, with no decimal point, is called an integer. 1, 6, 0, and -25 are all integers.

Numbers do not go in quotes. 6 is a number, and "6" is a string that happens to hold the character 6. That difference will matter later, when you do math with numbers. Try this in the shell:

>>> 2 + 3
5
>>> "2" + "3"
'23'

Adding two numbers gives you their sum. Adding two strings sticks them together.

random.randint()

This line rolls the die and prints the result:

print(f"{random.randint(1,6)}")

randint is short for “random integer.” It returns a random whole number.

Two Arguments

This is the first function you have called with two arguments. They are separated by a comma. The first argument, 1, is the smallest number you want. The second, 6, is the largest. randint() returns a number between them, and both ends are included, so you can get a 1 or a 6.

>>> import random
>>> random.randint(1, 6)
3
>>> random.randint(1, 6)
6
>>> random.randint(1, 20)
17

The code in the program writes randint(1,6) with no space after the comma. Python does not care about that space. Most Python programmers put one in, as in randint(1, 6), because it is a little easier to read. With a screen reader, the space makes the two numbers easier to hear as separate values.

Order Matters

The smaller number must come first. Try it the other way around:

>>> random.randint(6, 1)
Traceback (most recent call last):
  ...
ValueError: empty range in randint(6, 1)

Python says the range is empty, because there are no numbers that are at least 6 and also at most 1.

Summary

You rolled a die with one line of code. You learned that:

  • An integer is a whole number. Numbers are not put in quotes.
  • random.randint(low, high) returns a random integer from low to high, including both.
  • When a function takes more than one argument, you separate them with commas.
