Pig: A Dice Game for Many Players

Pig is a simple dice game with a hard choice at its heart. On your turn you roll a die again and again, adding up points. You can stop whenever you like and keep what you have. But if you roll a 1, you lose every point you earned that turn. Do you play it safe or push your luck?

This program is much longer than the ones before it. It handles from two to ten players, keeps everyone’s score, takes turns, and decides who wins. You will use almost everything you have learned so far, and some new tools as well.

The program also has a few bugs. That is normal. Real programs almost always do. At the end of the lesson you will track them down and fix them.

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

How to Play Pig

  • Two to ten people can play.
  • A die is rolled to choose who goes first.
  • On your turn, you roll one die. The number you roll is added to your score.
  • After each roll you choose to roll again or stop.
  • If you stop, you keep your points and the next player takes a turn.
  • If you roll a 1, your turn is over and you lose all the points you earned this turn. Points from earlier turns are safe.
  • The first player to reach 100 points wins.

Planning the Program

The folder for this program has two text files that were used to plan it. pig.txt has the rules. pig_steps.txt has a list of steps the program needs, written in plain English, in no special order:

  • Get how many players for the game.
  • Get the names of the players.
  • Choose who the first player is by rolling a die.
  • Roll the die for the player.
  • Add the roll to the total for this turn and to the player’s score.
  • Display the players and scores.
  • Check to see if someone wins.
  • Ask the player if they want to roll again.
  • Change to the next player.
  • Display a winning message.
  • Load the random, time, and sound modules.

Writing the steps down first, before any code, is a great habit. Once you have the list, put the steps in order. Then notice which ones repeat. “Roll the die” repeats many times in one turn, and turns repeat until someone wins. Things that repeat become loops.

Here is the plan in order:

  1. Load the modules.
  2. Ask how many players. Keep asking until the answer is from 2 to 10.
  3. Ask for each player’s name.
  4. Say the players’ names.
  5. Roll to choose the first player.
  6. Until someone wins:
    1. Roll the die. Add the roll to the turn total and the player’s score.
    2. If the roll is 1, take away the turn total and move to the next player.
    3. Say everyone’s score, and check whether anyone has 100.
    4. If someone has won, say so and stop.
    5. Ask the player whether to roll again. If not, move to the next player.

The Source Code for Pig

This program plays sounds, so install playsound with pip install playsound if you have not already. Type the program and save it as pig_dice.py in the folder that holds the sounds folder.

"""Fun simple Pig dice game
"""
import random
import time
import playsound as ps

number_players = 0
while number_players < 2 or number_players > 10:
    number_players = int(input("How many players are playing:  (2-10)"))

player_names = [""] * number_players
player_scores = [0] * number_players

for i, _ in enumerate(player_names):
    player_names[i] = input(f"Enter player {i+1} name:  ")

# display players
print("Players:")
for index, name in enumerate(player_names):
    print(f"{index+1}. {name}")
time.sleep(1)

# choose starting player
index = random.randint(0, number_players - 1)
print(f"Rolling a {number_players} sided die to choose the player to start.")
time.sleep(1.5)

index = random.randint(0, number_players - 1)
ps.playsound("sounds/dice.wav")

time.sleep(1)
print(f"{index +1 } was rolled.  {player_names[index]} rolls first.")
time.sleep(1)


winner = False
while not winner:
    total_round = 0
    again = ""
    while again.upper() != "N":
        roll = random.randint(1, 6)
        total_round += roll
        player_scores[index] += roll
        ps.playsound("sounds/dice.wav")
        print(f"{player_names[index]} rolls a: {roll}")
        time.sleep(1)

        if roll == 1:
            print(f"Pig Tails you lose this rounds points.")
            time.sleep(1)
            player_scores[index] -= total_round
            index = (index + 1) % number_players

        print("The scores are: ")
        for i, name in enumerate(player_names):
            if player_scores[i] >= 100:
                winner = i
            print(f"{name} Score: {player_scores[i]}")
        print("")
        time.sleep(1)

        if roll == 1:
            print(f"Switching to {player_names[index]}s turn. and rolling.")
            total_round = 0
            continue

        if winner:
            print(f"{player_names[index]} Wins!")
            break
        time.sleep(0.5)

        again = ""
        while again.upper() not in ["Y", "N"]:
            again = input(
                f"{player_names[index]} do you want to roll again?  (Y)es / (No):  "
            )

        if again.upper() == "N":
            index = (index + 1) % number_players
            print(f"Switching to {player_names[index]}s turn. and rolling.")
            total_round = 0
            time.sleep(1)

The program does not use any functions of its own. It runs from top to bottom, with loops to repeat the parts that repeat. You will learn to break programs like this into functions in later lessons.

Importing the time Module

import random
import time
import playsound as ps

The new module is time. It has functions that deal with time. This program uses just one of them, time.sleep().

Pausing with time.sleep()

time.sleep() pauses the program for the number of seconds you give it. The number can have a decimal point, so time.sleep(0.5) pauses for half a second.

Pauses matter a lot in a game played by ear. Without them, the roll, the scores, and the next question would all be printed at once, and the screen reader would race through them. A short pause after each event gives the player time to hear it and understand it before the next thing happens.

Asking for the Number of Players

number_players = 0
while number_players < 2 or number_players > 10:
    number_players = int(input("How many players are playing:  (2-10)"))

Converting a String to a Number with int()

input() always returns a string. Even if the player types 4, the program gets the string "4". You cannot compare a string with the number 2 using <, so the program changes the string into a number with int().

>>> int("4")
4
>>> int("4") + 1
5
>>> "4" + 1
Traceback (most recent call last):
  ...
TypeError: can only concatenate str (not "int") to str

The line int(input(...)) has one function call inside another. Python works from the inside out. First it calls input() and gets a string. Then it passes that string to int() and gets a number.

Comparison Operators

You already know ==, which checks whether two values are the same. Here are the others. Each one gives True or False:

  • < less than
  • > greater than
  • <= less than or equal to
  • >= greater than or equal to
  • != not equal to
>>> 3 < 2
False
>>> 12 > 10
True
>>> 100 >= 100
True
>>> "N" != "Y"
True

With a screen reader, listen carefully for these. “Less” and “greater” are easy to mix up when they are read as symbols. Some people find it helps to think of < as “is smaller than” and > as “is bigger than.”

The or Operator

The while condition uses or to join two comparisons:

number_players < 2 or number_players > 10

An or expression is True if either side is True. So the loop keeps going if the number is too small or too big. It stops only when the number is from 2 to 10.

number_players starts at 0 so the loop runs at least once, the same trick you used with the empty string in the coin guessing game.

Making Lists for Names and Scores

player_names = [""] * number_players
player_scores = [0] * number_players

Multiplying a list by a number makes a new, longer list with the items repeated.

>>> [""] * 3
['', '', '']
>>> [0] * 4
[0, 0, 0, 0]

So if there are three players, player_names starts as three empty strings, and player_scores starts as three zeros. The two lists line up. Player 0’s name is player_names[0] and player 0’s score is player_scores[0]. Lists that line up like this are sometimes called parallel lists.

Getting the Names with enumerate()

for i, _ in enumerate(player_names):
    player_names[i] = input(f"Enter player {i+1} name:  ")

Changing a List Item

You can put a new value into one spot in a list by using its index on the left side of =:

>>> names = ["", "", ""]
>>> names[1] = "Ben"
>>> names
['', 'Ben', '']

enumerate()

When you loop over a list, you usually get each item. Sometimes you also need to know the item’s index. enumerate() gives you both. Each time through the loop you get two values: the index and the item. You name both in the for line, separated by a comma.

>>> for index, name in enumerate(["Ana", "Ben", "Cam"]):
...     print(index, name)
...
0 Ana
1 Ben
2 Cam

In the name loop, the item is an empty string that will be replaced, so the program does not need it. It names that variable _, an underscore. That is a signal to readers that the value is ignored.

Counting from One for People

Python counts from 0, but people count from 1. The prompt says Enter player {i+1} name:, so the first player hears “player 1,” not “player 0.” The +1 happens inside the curly braces. You can put math inside an f-string, not just variable names.

Announcing the Players

print("Players:")
for index, name in enumerate(player_names):
    print(f"{index+1}. {name}")
time.sleep(1)

This loop uses both values from enumerate() to read out a numbered list, and then pauses for one second.

Choosing Who Goes First

index = random.randint(0, number_players - 1)
print(f"Rolling a {number_players} sided die to choose the player to start.")
time.sleep(1.5)

index = random.randint(0, number_players - 1)
ps.playsound("sounds/dice.wav")

The variable index will hold the index of the player whose turn it is. For three players, the indexes are 0, 1, and 2, so the program picks a random number from 0 to number_players - 1.

Did you notice that the same randint() line appears twice? The first result is thrown away, because the second line puts a new value in index. The first line does no harm, but it does nothing useful either. Programs often collect leftover lines like this as they are changed. Removing it is one of the exercises.

print(f"{index +1 } was rolled.  {player_names[index]} rolls first.")

Again, index + 1 turns the index into a number people expect. The player’s name comes from player_names[index].

The Main Game Loop

Now for the heart of the game. There are two loops, one inside the other:

winner = False
while not winner:
    total_round = 0
    again = ""
    while again.upper() != "N":
        ...

Flag Variables and not

winner is a flag. A flag is a variable that remembers whether something has happened. It starts as False, because no one has won yet. When someone wins, the program changes it.

not flips a Boolean. not False is True, and not True is False. So while not winner: reads naturally as “while there is no winner.”

Loops Inside Loops

Each time the outer loop runs, one player takes one whole turn. Each time the inner loop runs, the current player rolls the die once. A turn has many rolls, and a game has many turns.

When you read nested loops with a screen reader, listen to the indentation. The outer while is at zero spaces. The inner while is at four spaces. The lines inside the inner loop are at eight spaces. When you hear the indentation drop back to four, you have left the inner loop.

At the start of each turn, the outer loop sets total_round, the points earned this turn, back to 0. It also sets again to an empty string so the inner loop will run.

The inner loop keeps going while again.upper() != "N", meaning until the player says no.

Rolling the Die

roll = random.randint(1, 6)
total_round += roll
player_scores[index] += roll
ps.playsound("sounds/dice.wav")
print(f"{player_names[index]} rolls a: {roll}")
time.sleep(1)

The += and -= Operators

total_round += roll is a short way to write total_round = total_round + roll. It adds the roll to whatever is already in total_round. There is also -=, which subtracts.

>>> score = 10
>>> score += 4
>>> score
14
>>> score -= 6
>>> score
8

The roll is added in two places. total_round keeps track of this turn only. player_scores[index] is the player’s whole score. The program needs both, because a roll of 1 takes away only this turn’s points.

Rolling a 1

if roll == 1:
    print(f"Pig Tails you lose this rounds points.")
    time.sleep(1)
    player_scores[index] -= total_round
    index = (index + 1) % number_players

If the roll is 1, the program subtracts the points from this turn, including the 1 that was just added. Then it moves to the next player.

Taking Turns with %

The % sign is the modulo operator. It gives the remainder after division.

>>> 7 % 3
1
>>> 6 % 3
0
>>> 2 % 3
2

(index + 1) % number_players is a classic trick for taking turns in a circle. With three players, watch what happens:

  • Index 0 becomes 1 % 3, which is 1.
  • Index 1 becomes 2 % 3, which is 2.
  • Index 2 becomes 3 % 3, which is 0.

After the last player, it wraps back around to the first. You will use this trick in many games.

Announcing the Scores

print("The scores are: ")
for i, name in enumerate(player_names):
    if player_scores[i] >= 100:
        winner = i
    print(f"{name} Score: {player_scores[i]}")
print("")
time.sleep(1)

This loop reads every player’s name and score. While it is at it, it checks whether anyone has 100 or more. If someone does, it stores that player’s index in winner. Hold on to that idea. It is the source of the biggest bug in the program.

print("") prints an empty line. It gives the screen reader a short break between the scores and the next message.

continue and break

if roll == 1:
    print(f"Switching to {player_names[index]}s turn. and rolling.")
    total_round = 0
    continue

if winner:
    print(f"{player_names[index]} Wins!")
    break
time.sleep(0.5)

continue jumps straight back to the top of the loop it is in, skipping the rest of the block. Here, after a 1, the program has already moved to the next player, so it skips the “roll again?” question. Back at the top of the inner loop, again is not "N", so the loop runs again and the new player rolls right away. That is why the message says “and rolling.”

break ends the loop it is in right away. Python jumps to the first line after the loop. Here, when someone wins, the program says so and breaks out of the inner loop. Then the outer loop checks not winner, finds that there is a winner, and the game is over.

Both continue and break affect only the innermost loop they are in.

Asking to Roll Again

again = ""
while again.upper() not in ["Y", "N"]:
    again = input(
        f"{player_names[index]} do you want to roll again?  (Y)es / (No):  "
    )

if again.upper() == "N":
    index = (index + 1) % number_players
    print(f"Switching to {player_names[index]}s turn. and rolling.")
    total_round = 0
    time.sleep(1)

This is a third loop, inside the inner loop. It is the same “ask until the answer is good” pattern you used in the coin game.

The call to input() is split across three lines. Python lets you break a line inside parentheses, which helps keep long lines short. The prompt ends with a space, so the player’s answer does not run into the word “No.”

If the player says no, the program moves to the next player. Then, back at the top of the inner loop, again is "N", so the inner loop ends. The outer loop starts a new turn with total_round and again reset.

Finding the Bugs

Now that you understand the program, you can find its bugs. A bug is any place where a program does something its author did not intend.

Bug 1: Player 1 Can Never Win

Remember how the program records a winner:

if player_scores[i] >= 100:
    winner = i

and later checks it:

if winner:

When Python uses a number as a condition, 0 counts as False and any other number counts as True. Try it:

>>> if 0:
...     print("yes")
... else:
...     print("no")
...
no

The first player’s index is 0. When the first player reaches 100, winner is set to 0, which counts as False. The game does not end. It keeps going, and the first player’s score keeps growing past 100 with no winner. Every other player’s index is 1 or more, so they can win.

This is a classic bug. One clean fix is to store True instead of the index:

if player_scores[i] >= 100:
    winner = True

The program already knows who won. It is the current player, player_names[index], because only the current player’s score changes.

Bug 2: Typing a Word Crashes the Program

If the player types two or just presses Enter at the first question, int() cannot turn it into a number:

ValueError: invalid literal for int() with base 10: 'two'

The program stops with an error. You will learn a tool for handling errors like this, called try and except, in a later lesson. For now, you can check the string first with the isdigit() method, which returns True if every character is a digit:

>>> "4".isdigit()
True
>>> "two".isdigit()
False
>>> "".isdigit()
False

Small Things for the Ear

Some messages could sound better:

  • f"Pig Tails you lose this rounds points." is an f-string with no braces. It works, but the f is not needed.
  • Bens turn should be Ben's turn, and rounds points should be round's points.
  • Switching to Ben's turn. and rolling. has a period in the middle of the sentence. A screen reader will pause there.
  • The prompt (Y)es / (No) would be clearer as (Y)es / (N)o, or just Type Y or N:.

Summary

Pig is the biggest program you have written so far. You learned that:

  • Planning in plain English first makes a big program easier to write.
  • int() turns a string of digits into a number.
  • <, >, <=, >=, ==, and != compare values.
  • or is True if either side is True. not flips True and False.
  • [0] * 4 makes a list of four zeros.
  • enumerate() gives you each item’s index and value.
  • time.sleep() pauses, which gives players time to listen.
  • += and -= add to or subtract from a variable.
  • (index + 1) % count moves to the next player and wraps around.
  • continue jumps to the top of a loop. break leaves it.
  • A flag variable remembers whether something has happened.
  • 0 counts as False in a condition, which can cause sneaky bugs.
