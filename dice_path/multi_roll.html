Rolling Many Dice

Some dice games, such as Yahtzee, roll five dice at once. You could copy the roll line five times, but there is a better way. In this lesson you will use a for loop to repeat a line as many times as you want.

You will also learn a safer way to tell playsound where your sound file is, using the os module.

Topics covered in this lesson

  • for loops and the range() function
  • Constants
  • The os module, os.getcwd(), and os.path.join()
  • Full paths and relative paths
  • Comments at the end of a line

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

Sample Run

You hear the dice sound, and then five numbers, each on its own line:

1
1
1

Getting Ready

This program uses the playsound module, so install it with pip install playsound if you have not already. It plays dice.wav from the sounds folder. Run the program from the folder that holds both the program and the sounds folder.

The Source Code for Multi Roll

Type this program and save it as multi_roll.py:

import random
import playsound as ps
import os

# Paths for all sounds.  playsound requires full paths to work
CURRENT_DIRECTORY = os.getcwd()  # gets the scripts full working directory
DICE_SOUND = os.path.join(CURRENT_DIRECTORY, "SOUNDS", "dice.wav")


ps.playsound(DICE_SOUND)
for i in range(5):
    print(f"{random.randint(1,6)}")

The os Module

The program imports three modules. You know random and playsound. The new one is os:

import os

os stands for “operating system.” The operating system is the main program that runs your computer, such as Windows, macOS, or Linux. The os module has functions for working with files, folders, and other parts of the computer.

Full Paths

The comment above the next lines says that playsound needs full paths. A full path, also called an absolute path, names every folder starting from the top of the drive, such as:

C:\Users\Sam\python\dice_path\sounds\dice.wav

A relative path, such as sounds/dice.wav, starts from whatever folder you are in. Some versions of playsound have trouble with relative paths, so this program builds a full path.

os.getcwd()

CURRENT_DIRECTORY = os.getcwd()  # gets the scripts full working directory

os.getcwd() stands for “get current working directory.” Directory is another word for folder. The current working directory is the folder you were in when you ran the program. The function returns its full path as a string.

>>> import os
>>> os.getcwd()
'C:\\Users\\Sam\\python\\dice_path'

On Windows, the shell shows each backslash twice. That is just how Python displays a backslash inside a string. The real path has one backslash between each folder.

The comment at the end of the line says it gets the script’s directory. That is only true if you run the program from the folder it is saved in. If you run it from some other folder, os.getcwd() returns that other folder. So you still need to run the program from its own folder.

Comments at the End of a Line

That line also shows that a comment does not have to be on its own line. It can come after code. Python runs the code and ignores everything from the # on. Many programmers put two spaces before the # to make it easier to see where the code ends.

os.path.join()

DICE_SOUND = os.path.join(CURRENT_DIRECTORY, "SOUNDS", "dice.wav")

os.path.join() glues folder and file names together into one path. It puts the right separator between them for your computer, a backslash on Windows and a forward slash on Mac and Linux. You can give it as many pieces as you need.

>>> os.path.join("C:\\Users\\Sam", "sounds", "dice.wav")
'C:\\Users\\Sam\\sounds\\dice.wav'

Using os.path.join() instead of typing slashes yourself means your program works on any computer.

A Hidden Problem

Look closely at the folder name in that line: "SOUNDS", in capital letters. The real folder is named sounds, in lowercase. On Windows, file and folder names are not case sensitive, so the program works. On a Mac or Linux they usually are, and the program would not find the file. Fixing this is one of the exercises. It is a good reminder to spell file names exactly.

Constants

The variables CURRENT_DIRECTORY and DICE_SOUND are written in all capital letters. That is a signal to anyone reading the code. A variable named in capitals is a constant: it is set once, at the top of the program, and never changed.

Python does not stop you from changing a constant. The capital letters are a promise between programmers. Putting important settings, such as file paths, in constants at the top makes them easy to find and change later.

The for Loop

Here is the new way to repeat code:

for i in range(5):
    print(f"{random.randint(1,6)}")

A for loop runs its block once for each item in a group of items. Listen for the indentation: the print() line is indented, so it is the block that repeats.

The range() Function

range(5) makes a group of five numbers: 0, 1, 2, 3, and 4. Like string indexes, it starts counting at 0, so it stops at 4, one less than 5.

You can see the numbers by turning the range into a list:

>>> list(range(5))
[0, 1, 2, 3, 4]

The Loop Variable

Each time through the loop, Python puts the next number into the variable i. The first time, i is 0. The second time, it is 1, and so on. Try it:

>>> for i in range(3):
...     print(f"Time number {i}")
...
Time number 0
Time number 1
Time number 2

In the shell, when a line ends with a colon, the prompt changes to three dots, .... That means Python is waiting for the indented block. Type four spaces, then the line. When you are done with the block, press Enter on an empty line.

This program does not use i inside the loop. It only needs to repeat five times. Some programmers name a loop variable _, the underscore, to show that it is not used. You will see that in later programs.

for or while?

You have now seen two kinds of loops. Use a for loop when you know how many times to repeat, such as five dice. Use a while loop when you want to repeat until something happens, such as the player typing a good answer.

Summary

You rolled five dice with a loop. You learned that:

  • A for loop runs its block once for each item.
  • range(5) gives the numbers 0 through 4.
  • The os module works with files and folders.
  • os.getcwd() returns the folder you ran the program from.
  • os.path.join() builds a path with the right separators.
  • Names in all capitals are constants that should not change.
  • A comment can come at the end of a line of code.
