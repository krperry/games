Tic Tac Toe with Functions

You have built every piece of a Tic Tac Toe game: a board in a list, a function to read the board, functions to let a player mark a square, and a function to check for a winner. In this lesson you will put those pieces together into a complete two-player game.

Compare this program with no_functions.py. They play the same game, but this one is built from functions. The part that runs the game is just a few lines long and reads almost like plain English.

Topics covered in this lesson

  • Building a program from functions you already wrote and tested
  • A game() function with the game loop
  • if __name__ == "__main__":
  • Reading a program from the top down

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

How to Play

Two players share the keyboard. X goes first. On your turn, type the number of an empty square:

  • Top row: 1, 2, 3
  • Middle row: 4, 5, 6
  • Bottom row: 7, 8, 9

Get three in a row, across, down, or corner to corner, to win. If the board fills up first, it is a cat’s game.

The Source Code for Tic Tac Toe

Type this program and save it as tic_tac_toe.py:

"""Create functions to mark and display a spot by a player"""

game_state = ["X", 1, 2, 3, 4, 5, 6, 7, 8, 9, "X", 0]


def display_board():
    """this function displays the board"""
    print(f" {game_state[1]} | {game_state[2]} | {game_state[3]} ")
    print("---|---|---")
    print(f" {game_state[4]} | {game_state[5]} | {game_state[6]} ")
    print("---|---|---")
    print(f" {game_state[7]} | {game_state[8]} | {game_state[9]} ")


def mark_spot(position, mark):
    """a function to place a 'X' or 'O' and checkk if it is legal.
    *  argument s:
    *  position = Where you want to put the piece*
    * mark 'X' or 'O'
    *  returns
    *  True for placed False for fail
    """
    if game_state[position] not in ["X", "O"]:
        game_state[position] = mark
        return True
    return False


def player_input(mark):
    """this asks a player for a position and loops until it is legal
    Use the mark_spot function
    """
    choice = input(f"Enter a position for '{mark}': ")
    while choice not in [str(x) for x in game_state[1:10] if x not in ["X", "O"]]:
        print("incorrect position")
        choice = input(f"Enter a position for '{mark}': ")
    mark_spot(int(choice), mark)
    print(f"You placed an '{mark}'  in square {int(choice)}")


def check_winner():
    """checks for a winner
    prints who wins and set 'R' to restart game
    """
    # first row check
    for i in [1, 2, 3, 4, 7]:
        # row check
        if i in [1, 4, 7] and game_state[i : i + 3] == [game_state[i]] * 3:
            print(f"'{game_state[i]}' wins")
            game_state[0] = "R"
            return
        # Column check
        if i < 4 and game_state[i:10:3] == [game_state[i]] * 3:
            print(f"'{game_state[i]}' wins!")
            game_state[0] = "R"
            return

    # now test         down slope
    if game_state[1:10:4] == [game_state[1]] * 3:
        print(f"'{game_state[1]}' wins!")
        game_state[0] = "R"
        return

    # now test up slope
    if game_state[3:8:2] == [game_state[3]] * 3:
        print(f"'{game_state[3]}' wins!")
        game_state[0] = "R"
        return

    # If more moves return
    if [x for x in game_state[1:10] if x not in ["X", "O"]]:
        return

    print("Cats game!")
    game_state[0] = "R"
    return


def game():
    player = "X"
    display_board()
    while True:
        player_input(player)
        display_board()
        check_winner()
        if game_state[0] == "R":
            quit()
        if player == "X":
            player = "O"
        else:
            player = "X"


if __name__ == "__main__":
    game()

How the Program Is Organized

The program has five functions:

  • display_board() reads the board. You wrote it in display_board.py.
  • mark_spot() puts a mark on an empty square. You wrote it in mark_square.py.
  • player_input() asks a player for a free square and marks it. Also from mark_square.py.
  • check_winner() checks for a winner or a full board. You wrote it in check_winner.py.
  • game() runs the game. This is the only new function.

At the bottom, the if __name__ == "__main__": lines call game() when you run the file.

Each of the first four functions was written and tested in its own small program. Now they are copied here. Since you know each one works, you only need to think about how they fit together. If any of them is new to you, go back to the lesson where it was introduced.

Reading a Program from the Top Down

When you start reading a program you did not write, it helps to start with the function that runs everything, and only look inside the other functions when you need to. With a screen reader, you can jump to the bottom of the file, find which function is called, and read that one first.

Here, the bottom of the file calls game(). So read game() first.

The game() Function

def game():
    player = "X"
    display_board()
    while True:
        player_input(player)
        display_board()
        check_winner()
        if game_state[0] == "R":
            quit()
        if player == "X":
            player = "O"
        else:
            player = "X"

Read it out loud, and it is almost the rules of the game:

  1. X goes first. Read the board.
  2. Over and over:
    1. Let the player choose a square.
    2. Read the board.
    3. Check for a winner.
    4. If the game is over, quit.
    5. Switch players.

Each step is one short line, because each function hides the details. You do not need to know how check_winner() works to understand game(). You only need to know what it does. That is the real power of functions: they let you think about one level at a time.

Better Than no_functions.py

This version fixes problems from no_functions.py:

  • player starts as "X" and switches after each turn, which is easier to understand than starting as "O" and switching first.
  • check_winner() uses return, so a winner is announced only once, and a winning last move is not also called a cat’s game.
  • The board-printing code is written once, not twice.

How the Functions Share Information

The functions share information in two ways:

  • Through arguments. game() tells player_input() whose turn it is by passing player as an argument.
  • Through the global game_state list. player_input() changes the board, display_board() reads it, and check_winner() reads it and sets the game-over flag at index 0. Then game() checks the flag.

The Main Check

if __name__ == "__main__":
    game()

As you learned in the main.py lesson, this calls game() only when the file is run directly. If another program imports tic_tac_toe.py to use its functions, the game does not start on its own. Here the starting function is named game() instead of main(). The name is up to you.

Designing for the Ear

The game confirms each move out loud and reads the board after every move. That gives the player everything they need. Some ideas to make it even better:

  • Say whose turn it is in a full sentence, such as It is O's turn.
  • Let the player type B to hear the board again, instead of a square number.
  • Use the spoken board from the simple_display.py lesson, with “Top row,” “Middle row,” and “Bottom row.”
  • Play a sound when a mark is placed, and a different one when someone wins.

Summary

You put tested functions together into a complete game. You learned that:

  • A program built from small, tested functions is easy to put together.
  • A short function that calls other functions can read like plain English.
  • Start reading a program at the function that runs everything.
  • Functions share information through arguments and global variables.
