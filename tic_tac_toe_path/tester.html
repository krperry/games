Planning the Tic Tac Toe Board

Every Tic Tac Toe program in this folder starts with the same line. It makes a list called game_state that holds everything the game needs to remember: the nine squares of the board and a few extra settings.

This lesson is about that one line. Before you write any game, you have to decide how to store its information. That choice is called the game’s data design, and a good one makes the rest of the code much simpler. You will also learn how to explore a list like this in the interactive shell.

Topics covered in this lesson

  • Designing how a game stores its information
  • A list that mixes strings and numbers
  • Why the board starts at index 1
  • Using the interactive shell with a file, python -i
  • Changing items in a list

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

The Source Code for Tester

Type this line and save it as tester.py:

game_state = ["X", 1, 2, 3, 4, 5, 6, 7, 8, 9, "X", 0]

When you run it, nothing is printed. The program only makes a list. The fun is in exploring it.

The Tic Tac Toe Board

Tic Tac Toe is played on a grid of three rows and three columns. In these programs, the nine squares are numbered like a phone keypad, from the top left to the bottom right:

  • Top row: 1, 2, 3
  • Middle row: 4, 5, 6
  • Bottom row: 7, 8, 9

To make a move, a player types the number of an empty square. That works very well with a screen reader and a number pad. There is nothing to see and nothing to click.

What Is in game_state

The list has twelve items. Here is what each index holds, as described in the comments of the full game, hard-tic.py:

  • Index 0: a setting for the game, such as which mark the player chose, "X" or "O". Later programs also put "R" here when a game is over, and "Q" when the player wants to quit.
  • Indexes 1 through 9: the nine squares of the board.
  • Index 10: the difficulty level, for games against the computer.
  • Index 11: the number of players, 1 or 2.

Why the Board Starts at Index 1

Python counts list indexes from 0, but the board’s squares are numbered from 1 to 9. If the board were at indexes 0 through 8, the program would have to subtract 1 every time a player typed a square, and it would be easy to get wrong.

Instead, the board is at indexes 1 through 9. Index 0 is used for something else. Now square 5 is game_state[5]. The number the player types is the index. No math, no off-by-one errors.

Empty Squares Hold Their Own Number

At the start, square 1 holds the number 1, square 2 holds 2, and so on. When a player takes a square, the number is replaced with "X" or "O".

This is a clever design for two reasons. First, when the board is printed, each empty square says its own number, so the player always knows which numbers they can type. Second, no two empty squares are ever equal, because they all hold different numbers. That will matter a lot when you check for a winner: three squares in a row are a win only if they are equal, and empty squares can never be equal to each other.

A List of Mixed Types

This list holds both strings, like "X", and numbers, like 1. Python lets you mix types in one list. Some languages do not.

Exploring with python -i

You can run a file and then stay in the interactive shell with everything the file made. Type this at the command prompt:

python -i tester.py

The -i stands for “interactive.” The program runs, and then you get the >>> prompt, with game_state ready to use. Try these:

>>> game_state[5]
5
>>> game_state[0]
'X'
>>> game_state[1:10]
[1, 2, 3, 4, 5, 6, 7, 8, 9]

The last one is a slice. game_state[1:10] gives you a new list with the items from index 1 up to, but not including, index 10. That is exactly the board. You will learn more about slices in the next few lessons.

Now make a move. Put an X in the center square:

>>> game_state[5] = "X"
>>> game_state[1:10]
[1, 2, 3, 4, 'X', 6, 7, 8, 9]

And an O in the top left corner:

>>> game_state[1] = "O"
>>> game_state[1:10]
['O', 2, 3, 4, 'X', 6, 7, 8, 9]

Type exit() when you are done.

python -i is a great tool for any program. When something goes wrong, run the program with -i, and you can look at every variable afterwards to find out why.

Summary

You planned how a Tic Tac Toe game stores its board. You learned that:

  • Deciding how to store a game’s information is the first step in writing it.
  • Putting the board at indexes 1 through 9 lets the square number be the index.
  • Empty squares hold their own number, so they can be read out and are never equal to each other.
  • A list can hold strings and numbers together.
  • python -i file.py runs a file and then opens the shell with its variables.
  • game_state[1:10] is a slice that gives you just the board.

Exercises

  2. In the shell, check whether the empty squares 4, 5, and 6 are equal. Why is the answer False?
  3. Use game_state[1:10].count("X") to count the X’s on the board.
  4. Add a comment above the line in tester.py that explains what each index holds.
  5. Think about it: what other ways could you store a Tic Tac Toe board? What would be harder or easier with each?
