Adding Up a Blackjack Hand

In Blackjack, the goal is to get cards that add up as close to 21 as you can without going over. Adding up a hand sounds easy, but there is a twist: an Ace can be worth 11 or 1, whichever is better for you. In this lesson you will write a function that adds up any hand correctly, Aces and all.

You will also test the function. The program runs the function on five hands where you already know the right answer, and prints both. If they match, the function works.

Topics covered in this lesson

  • Returning a value with return

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

How Cards Are Counted in Blackjack

  • Cards 2 through 9 are worth their number.
  • 10, Jack, Queen, and King are each worth 10.
  • An Ace is worth 11, unless that would put the hand over 21. Then it is worth

For example, an Ace and a 3 is 14, because the Ace counts as 11. But an Ace, a 3, and a 10 would be 24 with the Ace as 11, which is over 21. So the Ace counts as 1, and the hand is 14.

Every test matches. The function works.

The Source Code for Sum Hand

Type this program and save it as sum_hand.py:

"""A method to sum a card hand with test hands"""

test_hand_1 = [["Ace", "Clubs"], ["3", "Spades"]]
test_hand_2 = [["Ace", "Clubs"], ["3", "Spades"], ["7", "Hearts"]]
test_hand_3 = [["Ace", "Clubs"], ["3", "Spades"], ["10", "Hearts"]]
test_hand_4 = [["Ace", "Clubs"], ["3", "Spades"], ["10", "Hearts"], ["Ace", "Diamonds"]]
test_hand_5 = [["Ace", "Clubs"], ["3", "Spades"], ["5", "Hearts"], ["Ace", "Diamonds"]]


def sum_hand(hand):
    sum = 0
    aces = 0
    for card in hand:
        if card[0] in ["2", "3", "4", "5", "6", "7", "8", "9"]:
            sum += int(card[0])
        elif card[0] in ["10", "Jack", "Queen", "King"]:
            sum += 10
        else:
            aces += 1
            sum += 11
    while sum > 21 and aces:
        sum -= 10
        aces -= 1
    return sum


print(f"Test hand 1 sum: {sum_hand(test_hand_1)}, should be 14")
print(f"Test hand 2 sum: {sum_hand(test_hand_2)}, should be 21")
print(f"Test hand 3 sum: {sum_hand(test_hand_3)}, should be 14")
print(f"Test hand 4 sum: {sum_hand(test_hand_4)}, should be 15")
print(f"Test hand 5 sum: {sum_hand(test_hand_5)}, should be 20")

The Test Hands

test_hand_1 = [["Ace", "Clubs"], ["3", "Spades"]]

Each hand is a list of cards, and each card is a list of a rank and a suit, just like in the deck from cards.py. There are five test hands. Each one checks a different situation:

  1. Ace and 3. The Ace should be 11, for 14.
  2. Ace, 3, and 7. The Ace should be 11, for exactly 21.
  3. Ace, 3, and 10. The Ace must drop to 1, for 14.
  4. Two Aces, a 3, and a 10. Both Aces must drop to 1, for 15.
  5. Two Aces, a 3, and a 5. One Ace stays 11 and one drops to 1, for 20.

Good tests check the tricky cases, not just the easy ones. Here the tricky part is Aces, so most of the tests are about Aces.

Defining a Function with an Argument

def sum_hand(hand):

In the main.py lesson you defined a function with empty parentheses. This function has a parameter, hand, inside its parentheses. A parameter is a variable that gets its value when the function is called. When the program calls sum_hand(test_hand_1), the value of test_hand_1 is put into hand for that call.

That is what makes functions so useful. You write the code once, and then you can use it on any hand.

Counting the Cards

    sum = 0
    aces = 0
    for card in hand:
        if card[0] in ["2", "3", "4", "5", "6", "7", "8", "9"]:
            sum += int(card[0])
        elif card[0] in ["10", "Jack", "Queen", "King"]:
            sum += 10
        else:
            aces += 1
            sum += 11

The function keeps two counts. sum is the total so far. aces is the number of Aces in the hand.

The for loop looks at each card. card[0] is the rank, such as "7" or "King".

if, elif, and else

The loop checks three cases:

  • If the rank is 2 through 9, it adds the number. The rank is a string, so int(card[0]) turns "7" into 7 first.
  • Else if the rank is 10 or a face card, it adds 10.
  • Else, the card must be an Ace. It adds 11 and counts the Ace.

Only one of the three blocks runs for each card.

A Note on the Name sum

Python has a built-in function called sum() that adds up a list of numbers. This program uses sum as a variable name, which hides the built-in function inside sum_hand(). It works, because this function never needs the built-in one, but it is a habit to avoid. A name such as total is safer. You will fix this in an exercise.

Fixing the Aces

    while sum > 21 and aces:
        sum -= 10
        aces -= 1
    return sum

Every Ace was counted as 11. If the total is over 21, the program changes one Ace from 11 to 1 by subtracting 10. It keeps doing that until the total is 21 or less, or until it runs out of Aces to change.

Numbers as Conditions

The condition is sum > 21 and aces. The second part is just a number. When Python uses a number as a condition, 0 counts as False and any other number counts as True. So and aces means “and there is at least one Ace left to change.”

Let’s walk through test hand 4: Ace, 3, 10, Ace.

  • After the for loop, sum is 11 + 3 + 10 + 11 = 35, and aces is 2.
  • 35 is over 21 and aces is 2, so subtract 10. sum is 25, aces is 1.
  • 25 is over 21 and aces is 1, so subtract 10. sum is 15, aces is 0.
  • 15 is not over 21, so the loop stops.

The answer is 15. Walking through code by hand like this, with real numbers, is called tracing. It is one of the best ways to understand code, and it works just as well by ear as by sight.

return

return sum ends the function and sends the value of sum back to whoever called it. The call sum_hand(test_hand_4) becomes the value 15.

Running the Tests

print(f"Test hand 1 sum: {sum_hand(test_hand_1)}, should be 14")

Each of these lines calls the function inside an f-string and prints the result next to the answer it should be. When you listen to the output, you only need to check that the two numbers on each line match.

This is the simplest kind of testing, and it is very powerful. Later, when you change sum_hand(), you can run this program again and know right away if you broke something.

Summary

You wrote and tested a function that adds up a Blackjack hand. You learned that:

  • A function’s parameter gets its value from the argument in the call.
  • return sends a value back from a function.
  • if, elif, and else pick one of several cases.
  • int() turns a string of digits into a number.
  • 0 counts as False in a condition, and other numbers count as True.
  • Tracing code with real numbers helps you understand it.
  • Testing with known answers tells you whether a function works.
