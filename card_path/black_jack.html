A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

How to Play Blackjack

The black_jack.txt file in this folder explains the rules. Here they are in short:

  • You and the dealer each get two cards.
  • Cards 2 through 10 are worth their number. Jack, Queen, and King are worth 10. An Ace is worth 11, or 1 if 11 would put you over 21.
  • If either of you has exactly 21 with the first two cards, that is a blackjack, and the game is over right away.
  • On your turn, you can hit, which means take another card, or stay, which means stop.
  • If your total goes over 21, you bust and lose.
  • When you stay, the dealer plays. The dealer must hit while they have less than 17, and stay at 17 or more. This is the rule in casinos.
  • If the dealer busts, you win. Otherwise, the higher total wins. In this game, a tie goes to the dealer, which is called “the house.”

The Plan

The black_jack.txt file also has the plan the program follows:

  1. Set up the deck of cards.
  2. Shuffle the deck.
  3. Deal the first cards.
  4. Let the player hit or stay.
  5. Let the dealer play. If the dealer has less than 17, hit. At 17 or more, stay.
  6. Decide the winner.

The code follows these steps in this order, from top to bottom. As you read it, listen for the comments that mark each step.

The Source Code for Blackjack

This program plays sounds, so install playsound with pip install playsound if you have not already. Type it in and save it as black_jack.py in the folder that holds the sounds folder.

"""Black jack game"""
import random
import playsound as ps
import time
import sys  # used to exit game

cards = [
    "Ace",
    "2",
    "3",
    "4",
    "5",
    "6",
    "7",
    "8",
    "9",
    "10",
    "Jack",
    "Queen",
    "King",
]

clean_deck = []
for card in cards:
    for suit in ["Clubs", "Diamonds", "Hearts", "Spades"]:
        clean_deck.append([card, suit])

deck = clean_deck[:]  # copy a clean deck for use

random.shuffle(deck)  # Shuffle the deck.
ps.playsound("sounds/shuffle.wav")

# deal first four cards 2 for player 2 for dealer
for _ in range(4):
    sound = random.choice(["sounds/deal1.wav", "sounds/deal2.wav", "sounds/deal3.wav"])
    ps.playsound(sound)

player_hand = [deck.pop(), deck.pop()]
dealer_hand = [deck.pop(), deck.pop()]


def sum_hand(hand):
    sum = 0
    aces = 0
    for card in hand:
        if card[0] in ["2", "3", "4", "5", "6", "7", "8", "9"]:
            sum += int(card[0])
        elif card[0] in ["10", "Jack", "Queen", "King"]:
            sum += 10
        else:
            aces += 1
            sum += 11
    while sum > 21 and aces:
        sum -= 10
        aces -= 1
    return sum


def hand_string(hand):
    s = ""
    for card in hand:
        s += " ".join(card) + " "
    return s


def display_table():
    print(f"Dealer:\t{hand_string(dealer_hand)}\tTotal: {sum_hand(dealer_hand)}")
    print(f"Player:\t{hand_string(player_hand)}\tTotal: {sum_hand(player_hand)}")


display_table()
dealer_sum = sum_hand(dealer_hand)
player_sum = sum_hand(player_hand)

if dealer_sum == 21 and player_sum == 21:
    print("Dealer and Player both have black jack its a Tie and the House wins.")
    sys.exit()
if dealer_sum == 21:
    print("Dealer has a black jack.  Dealer wins.")
    sys.exit()
if player_sum == 21:
    print("Player has a black jack.  Player wins.")
    sys.exit()


# player plays
again = ""
while again.upper() != "S":
    player_sum = sum_hand(player_hand)
    if player_sum > 21:
        print(f"You have {player_sum}. You bust!  Dealer wins.")
        sys.exit()

    if player_sum == 21:
        print("You have 21. Now its the Dealers turn.")
        time.sleep(1)
        again = "S"
        continue

    again = ""
    while again.upper() not in ["H", "S"]:
        again = input("Do you want to (H)it or (S)tay")
    if again.upper() == "S":
        print("You stay.  Now it is the dealers turn.")
        time.sleep(1)
        continue

    print("You hit.")
    ps.playsound("sounds/deal1.wav")
    player_hand.append(deck.pop())
    display_table()
    time.sleep(1)

# dealer plays
dealer_sum = sum_hand(dealer_hand)
while dealer_sum < 17:
    print("Dealer hits.")
    ps.playsound("sounds/deal1.wav")
    dealer_hand.append(deck.pop())
    dealer_sum = sum_hand(dealer_hand)
    display_table()
    time.sleep(1)

if dealer_sum == player_sum:
    print(f"Dealer and Player has {player_sum}.  It is a tie and the Dealer wins")
elif dealer_sum > 21:
    print(f"Dealer has {dealer_sum}.  Dealer busts.  Player wins.")
elif dealer_sum > player_sum:
    print(f"Dealer has {dealer_sum} and Player has {player_sum}.  Dealer wins!")
else:
    print(f"Dealer has {dealer_sum} and Player has {player_sum}.  Player  wins!")

Steps 1 and 2: The Deck

cards = [
    "Ace",
    "2",
    ...
    "King",
]

This is the same list of ranks as in cards.py, but written with one rank per line. Python allows line breaks inside brackets. This style is much easier to move through with a screen reader, because each line holds just one item. The comma after the last item, "King",, is allowed too. It makes it easy to add another item later.

The deck is built with the same nested loops as before, copied with [:], and shuffled. Then the shuffle sound plays.

Step 3: Dealing

for _ in range(4):
    sound = random.choice(["sounds/deal1.wav", "sounds/deal2.wav", "sounds/deal3.wav"])
    ps.playsound(sound)

player_hand = [deck.pop(), deck.pop()]
dealer_hand = [deck.pop(), deck.pop()]

The loop plays four random deal sounds, one for each card. The loop variable is _ because the loop only needs to repeat. It never uses the number.

Taking Cards with pop()

pop() removes the last item from a list and returns it. Each call takes one card off the deck. So after these lines, the player has two cards, the dealer has two cards, and the deck has 48 cards left. No card can be dealt twice.

>>> deck = ["a", "b", "c"]
>>> deck.pop()
'c'
>>> deck
['a', 'b']

Each hand is made with two pop() calls inside square brackets, which makes a new list of the two cards.

Notice that the sounds are played first and the cards are dealt after. The player cannot tell the difference, since nothing is said until the table is read. Sounds and code do not always have to happen in the same order, as long as the player hears things in the right order.

The Functions

The program defines three functions: sum_hand(), hand_string(), and display_table(). They are the same functions you wrote in the last two lessons, copied into this program. You tested them there, so you can trust them here. That is one of the best reasons to build a program in small, tested pieces.

The functions are defined after the deal, in the middle of the program. That works, because Python only needs a function to be defined before it is called. Most programmers put all their functions near the top, after the imports, so they are easy to find.

Checking for Blackjack

display_table()
dealer_sum = sum_hand(dealer_hand)
player_sum = sum_hand(player_hand)

if dealer_sum == 21 and player_sum == 21:
    print("Dealer and Player both have black jack its a Tie and the House wins.")
    sys.exit()

    print("Dealer has a black jack.  Dealer wins.")
    sys.exit()
if player_sum == 21:
    print("Player has a black jack.  Player wins.")
    sys.exit()

After reading the table, the program checks for a blackjack. These are three separate if statements, not if and elif. That is fine here, because each one ends the program with sys.exit() if it is true. Nothing after it runs.

The Order of Checks Matters

The program checks for both players having 21 first. Think about what would happen if it checked dealer_sum == 21 first. When both had 21, the dealer check would be true, and the program would say the dealer wins and exit. It would never get to the “both” check. When one condition is part of another, check the more specific one first.

Step 4: The Player’s Turn

# player plays
again = ""
while again.upper() != "S":
    player_sum = sum_hand(player_hand)
    if player_sum > 21:
        print(f"You have {player_sum}. You bust!  Dealer wins.")
        sys.exit()

    if player_sum == 21:
        print("You have 21. Now its the Dealers turn.")
        time.sleep(1)
        again = "S"
        continue

    again = ""
    while again.upper() not in ["H", "S"]:
        again = input("Do you want to (H)it or (S)tay")
    if again.upper() == "S":
        print("You stay.  Now it is the dealers turn.")
        time.sleep(1)
        continue

    print("You hit.")
    ps.playsound("sounds/deal1.wav")
    player_hand.append(deck.pop())
    display_table()
    time.sleep(1)

The loop keeps going until again is "S", for stay. Each time through, it does these things in order:

  1. Add up the player’s hand. If it is over 21, the player busts, and the game ends.
  2. If it is exactly 21, there is no reason to hit again. The program sets again to "S" for the player and uses continue to jump to the top of the loop. The loop condition is now false, so the loop ends.
  3. Otherwise, ask “hit or stay?” until the answer is H or S.
  4. If the answer is S, say so and continue. Again, the loop ends.
  5. If the answer is H, play a deal sound, pop() a card from the deck, append() it to the player’s hand, and read the table again.

Notice how continue is used here. It skips the rest of the loop and goes back to the while line, where the condition is checked again. Since again is "S", the loop ends. It is a way of saying “this turn is done.”

Notice also that after a hit, the program goes back to the top of the loop, where it checks for a bust before asking again. So a player who busts is told right away and is never asked to hit or stay with more than 21.

Step 5: The Dealer’s Turn

# dealer plays
dealer_sum = sum_hand(dealer_hand)
while dealer_sum < 17:
    print("Dealer hits.")
    ps.playsound("sounds/deal1.wav")
    dealer_hand.append(deck.pop())
    dealer_sum = sum_hand(dealer_hand)
    display_table()
    time.sleep(1)

The dealer does not make choices. The dealer follows a fixed rule: hit while under 17. That fits perfectly in a while loop. Each time through, the dealer takes a card, the total is added up again, and the table is read.

It is important that dealer_sum is updated inside the loop. If it were not, the condition would never change, and the dealer would keep hitting forever.

Step 6: Who Won?

if dealer_sum == player_sum:
    print(f"Dealer and Player has {player_sum}.  It is a tie and the Dealer wins")
elif dealer_sum > 21:
    print(f"Dealer has {dealer_sum}.  Dealer busts.  Player wins.")
elif dealer_sum > player_sum:
    print(f"Dealer has {dealer_sum} and Player has {player_sum}.  Dealer wins!")
else:
    print(f"Dealer has {dealer_sum} and Player has {player_sum}.  Player  wins!")

By the time the program gets here, the player has not busted. That was checked during the player’s turn. So there are four possibilities, checked in order:

  1. A tie. The dealer wins ties in this game.
  2. The dealer busted. The player wins.
  3. The dealer has more. The dealer wins.
  4. Otherwise, the player has more. The player wins.

The order matters here, too. The bust check must come before the “dealer has more” check. A dealer with 24 has more than a player with 18, but the dealer has busted and should lose.

Designing for the Ear

The game reads the whole table after every card, which keeps the player informed. Here are some things that could make it even better by ear:

  • The prompt Do you want to (H)it or (S)tay has no space at the end, so the answer runs into the word Stay.
  • Now its the Dealers turn should be Now it's the dealer's turn.
  • In real Blackjack, one of the dealer’s first two cards is hidden until the dealer’s turn. This game shows both, which makes it a little easier for the player.
  • Saying King of Clubs, 2 of Clubs would be clearer than King Clubs 2 Clubs. You did this in the display_table.py exercises.

Summary

You built a complete Blackjack game from smaller pieces. You learned that:

  • A plan in plain steps becomes the outline of your code.
  • pop() takes a card off the deck so it cannot be dealt twice.
  • Functions that you tested in small programs can be reused in big ones.
  • sys.exit() ends the game as soon as the result is known.
  • continue jumps back to the loop’s condition.
  • A computer player that follows fixed rules fits in a while loop.
  • When conditions overlap, the order you check them in changes the result.
