Building and Shuffling a Deck of Cards

Card games are some of the most popular games in the world, and they work very well by ear. Before you can play a card game, though, you need a deck of cards. In this lesson you will build a full deck of 52 cards, shuffle it, and peek at a few cards before and after the shuffle.

To build the deck you will put one loop inside another and make a list of lists.

Topics covered in this lesson

  • Nested for loops
  • Lists of lists
  • The append() list method
  • Copying a list with [:]
  • Negative indexes
  • random.shuffle()
  • The join() string method
  • Single quotes inside an f-string

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

A Deck of Cards

A standard deck has 52 cards. There are four suits: clubs, diamonds, hearts, and spades. Each suit has thirteen ranks: 2 through 10, Jack, Queen, King, and Ace. Every rank comes in every suit, so 13 ranks times 4 suits makes 52 cards.

The Source Code for Cards

Type this program and save it as cards.py:

import random

cards = ["2", "3", "4", "5", "6", "7", "8", "9", "10", "Jack", "Queen", "King", "Ace"]

clean_deck = []
for card in cards:
    for suit in ["Clubs", "Diamonds", "Hearts", "Spades"]:
        clean_deck.append([card, suit])

deck = clean_deck[:]  # copy a clean deck for use

print("Before shuffling")
print(f"The top card is: {' '.join(deck[0])}")
print(f"The bottom card is: {' '.join(deck[-1])}")
print(f"The middle card is: {' '.join(deck[24])}")

random.shuffle(deck)  # Shuffle the deck.

print("After shuffling:")
print(f"The top card is: {' '.join(deck[0])}")
print(f"The bottom card is: {' '.join(deck[-1])}")
print(f"The middle card is: {' '.join(deck[24])}")

The List of Ranks

cards = ["2", "3", "4", "5", "6", "7", "8", "9", "10", "Jack", "Queen", "King", "Ace"]

This list holds the thirteen ranks as strings. Even the numbers are strings, such as "2", so every rank is the same kind of value. That makes them easy to print together.

This is a long line. When you read it with a screen reader, it can help to read it word by word, or to move through it with the arrow keys and count the commas. Python lets you split a list over several lines, one item per line, as long as the line breaks are inside the brackets. Many programmers do that for long lists.

Building the Deck

clean_deck = []
for card in cards:
    for suit in ["Clubs", "Diamonds", "Hearts", "Spades"]:
        clean_deck.append([card, suit])

An Empty List

clean_deck = [] makes a list with nothing in it. The loops will fill it.

The append() Method

Lists have methods, just like strings do. append() adds an item to the end of a list.

>>> hand = []
>>> hand.append("Ace")
>>> hand
['Ace']
>>> hand.append("King")
>>> hand
['Ace', 'King']

Unlike upper(), which makes a new string, append() changes the list itself. You do not need to store its result.

Lists Inside Lists

Each card is itself a list of two strings, the rank and the suit, such as ["Ace", "Spades"]. So the deck is a list of lists.

>>> deck = [["Ace", "Spades"], ["2", "Clubs"]]
>>> deck[0]
['Ace', 'Spades']
>>> deck[0][0]
'Ace'
>>> deck[0][1]
'Spades'

deck[0] is the first card. deck[0][0] is the first item of the first card, its rank. Read two sets of square brackets from left to right: first pick the card, then pick the part of the card.

Nested Loops

There are two for loops, one inside the other. Listen for the indentation: the second for is indented four spaces, and the append() line is indented eight. The inner loop runs all the way through for every single trip through the outer loop.

Here is what happens:

  • The outer loop sets card to "2". The inner loop then runs four times, adding the 2 of Clubs, the 2 of Diamonds, the 2 of Hearts, and the 2 of Spades.
  • The outer loop sets card to "3". The inner loop adds the four 3s.
  • This continues through all 13 ranks.

13 trips through the outer loop, times 4 trips through the inner loop, makes 52 calls to append(), and 52 cards.

Try a smaller version in the shell:

>>> for rank in ["A", "K"]:
...     for suit in ["C", "D"]:
...         print(rank, suit)
...
A C
A D
K C
K D

Copying the Deck

deck = clean_deck[:]  # copy a clean deck for use

[:] makes a copy of a list. Why copy it? Because of how lists and variables work. When you write deck = clean_deck without [:], you do not get a second list. You get a second name for the same list. Shuffling deck would also shuffle clean_deck, since they are the same list.

>>> a = [1, 2, 3]
>>> b = a
>>> b.append(4)
>>> a
[1, 2, 3, 4]
>>> c = a[:]
>>> c.append(5)
>>> a
[1, 2, 3, 4]

Adding to b changed a, because they are the same list. Adding to the copy, c, did not.

By keeping clean_deck in order and playing with a copy, a game can easily start over with a fresh deck.

Peeking at Cards

print("Before shuffling")
print(f"The top card is: {' '.join(deck[0])}")
print(f"The bottom card is: {' '.join(deck[-1])}")
print(f"The middle card is: {' '.join(deck[24])}")

Negative Indexes

deck[0] is the first card, the top of the deck. deck[-1] is the last card. Negative indexes count backward from the end. -1 is the last item, -2 is the one before it, and so on. This is handy because you do not need to know how long the list is.

>>> ranks = ["2", "3", "4", "5"]
>>> ranks[-1]
'5'
>>> ranks[-2]
'4'

deck[24] is the 25th card, near the middle of the deck.

The join() Method

Each card is a list, like ["Ace", "Spades"]. To say it out loud, the program needs the string "Ace Spades". The join() method does that. You call it on the string you want between the items, and you give it the list:

>>> " ".join(["Ace", "Spades"])
'Ace Spades'
>>> " of ".join(["Ace", "Spades"])
'Ace of Spades'
>>> ", ".join(["red", "green", "blue"])
'red, green, blue'

Notice the second example. " of " makes a card sound much more natural.

Quotes Inside an f-string

Look at this f-string:

f"The top card is: {' '.join(deck[0])}"

The f-string is in double quotes. The space string inside the braces is in single quotes, ' '. That matters. If you used double quotes inside, Python could think the f-string ended there. Using the other kind of quote inside keeps them apart. Listen carefully for the difference with punctuation reading on. Your screen reader will say “quote” for one and “tick” or “apostrophe” for the other.

Shuffling

random.shuffle(deck)  # Shuffle the deck.

random.shuffle() mixes up the items in a list into a random order. Like append(), it changes the list itself and does not return anything.

>>> numbers = [1, 2, 3, 4, 5]
>>> random.shuffle(numbers)
>>> numbers
[4, 1, 5, 3, 2]

Then the program prints the top, bottom, and middle cards again, so you can hear that they changed.

Summary

You built and shuffled a deck of 52 cards. You learned that:

  • A list can hold other lists. deck[0][1] picks the first card, then its suit.
  • append() adds an item to the end of a list.
  • A loop inside another loop runs all the way through for each trip through the outer loop.
  • [:] makes a copy of a list. Plain = gives the same list a second name.
  • Negative indexes count from the end. -1 is the last item.
  • random.shuffle() mixes up a list.
  • join() turns a list of strings into one string.
  • Use single quotes inside a double-quoted f-string.
