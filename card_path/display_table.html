Showing the Blackjack Table

In a Blackjack game, the player needs to know what is on the table: the dealer’s cards, their own cards, and the total for each. In this lesson you will write functions that turn a hand into words and read out the whole table.

This program builds on sum_hand.py. It uses the same sum_hand() function and adds two more. Together, these three functions are most of what the Blackjack game needs.

Topics covered in this lesson

  • Functions that call other functions
  • Building a string in a loop
  • Global variables
  • The tab character, \t
  • Printing a blank line
  • Testing by changing the data and running again

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

Sample Run

Dealer: Ace Clubs 3 Spades 10 Hearts    Total: 14

The Source Code for Display Table

Type this program and save it as display_table.py:

"""A method to sum a card hand with test hands"""

dealer_hand = [["Ace", "Clubs"], ["3", "Spades"]]
player_hand = [["Ace", "Clubs"], ["3", "Spades"], ["7", "Hearts"]]


def sum_hand(hand):
    sum = 0
    aces = 0
    for card in hand:
        if card[0] in ["2", "3", "4", "5", "6", "7", "8", "9"]:
            sum += int(card[0])
        elif card[0] in ["10", "Jack", "Queen", "King"]:
            sum += 10
        else:
            aces += 1
            sum += 11
    while sum > 21 and aces:
        sum -= 10
        aces -= 1
    return sum


def hand_string(hand):
    s = ""
    for card in hand:
        s += " ".join(card) + " "
    return s


def display_table():
    print(f"Dealer:\t{hand_string(dealer_hand)}\tTotal: {sum_hand(dealer_hand)}")
    print(f"Player:\t{hand_string(player_hand)}\tTotal: {sum_hand(player_hand)}")


display_table()

# blank line
print("")
dealer_hand = [["Ace", "Clubs"], ["3", "Spades"], ["10", "Hearts"]]
player_hand = [["Ace", "Clubs"], ["3", "Spades"], ["10", "Hearts"], ["Ace", "Diamonds"]]

display_table()

Turning a Hand into Words

def hand_string(hand):
    s = ""
    for card in hand:
        s += " ".join(card) + " "
    return s

This function builds a string that names every card in a hand.

Building a String in a Loop

s starts as an empty string. Each time through the loop, the program adds one card to the end of it. " ".join(card) turns ["Ace", "Clubs"] into "Ace Clubs", and then + " " adds a space after it so the next card does not run into it.

+= works on strings, too. It sticks the new string onto the end:

>>> s = ""
>>> s += "Ace Clubs "
>>> s += "3 Spades "
>>> s
'Ace Clubs 3 Spades '

Notice there is an extra space at the very end. You usually cannot hear a trailing space, but it is there.

Making It Easier to Hear

Ace Clubs 3 Spades 7 Hearts is hard to follow by ear. Where does one card end and the next begin? Is it “Clubs 3” or “3 Spades”? A comma between cards, and the word “of,” make a big difference: Ace of Clubs, 3 of Spades, 7 of Hearts.

join() can do both at once. You will try this in the exercises:

>>> hand = [["Ace", "Clubs"], ["3", "Spades"]]
>>> names = []
>>> for card in hand:
...     names.append(" of ".join(card))
...
>>> ", ".join(names)
'Ace of Clubs, 3 of Spades'

Reading the Table

def display_table():
    print(f"Dealer:\t{hand_string(dealer_hand)}\tTotal: {sum_hand(dealer_hand)}")
    print(f"Player:\t{hand_string(player_hand)}\tTotal: {sum_hand(player_hand)}")

Functions That Call Functions

display_table() calls hand_string() and sum_hand() inside its f-strings. Each function does one small job well, and bigger functions put them together. That is how good programs are built. If there is a bug in adding up hands, you know to look in sum_hand(). If the cards sound wrong, you look in hand_string().

Global Variables

display_table() has no parameters, but it uses dealer_hand and player_hand. Those variables were made outside any function, at the top of the file. A variable made outside any function is a global variable. Any function in the file can read it.

That is convenient, but it can make programs harder to understand, because you cannot tell from the def line what the function depends on. Another way would be to pass the hands in as arguments: def display_table(dealer_hand, player_hand):. You will see more about this in later lessons.

The Tab Character

\t inside a string is a tab character. The backslash and the letter t together stand for one character. On screen, a tab lines things up in columns, so the totals line up under each other.

By ear, a tab may be read as “tab,” as a pause, or as nothing. Columns are a visual idea. For a screen reader user, punctuation that makes a natural pause, such as a comma or a period, works better. For example:

print(f"Dealer has {hand_string(dealer_hand)}. Total: {sum_hand(dealer_hand)}.")

There are other backslash characters, too. The most common is \n, which starts a new line.

The program shows the table once, prints a blank line, puts new hands in the global variables, and shows the table again. Because display_table() reads the global variables each time it is called, the second call reads the new hands.

print("") prints an empty line. It makes a clear break between the two tests, and it gives the screen reader a moment of silence.

Summary

You wrote functions that read the Blackjack table out loud. You learned that:

  • Small functions that each do one job can be combined into bigger ones.
  • You can build a string bit by bit with +=.
  • A global variable is made outside any function, and functions can read it.
  • \t is a tab character, and \n is a new line.
  • Tabs line up columns on screen but may not help by ear.
  • print("") prints a blank line.
