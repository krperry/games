Dealing Cards with Sound

Now that you can build and shuffle a deck, it is time to deal. In this lesson the program shuffles the deck with a shuffling sound, asks how many cards to deal, and then deals them one at a time, with a different card sound for each.

Picking a random sound each time is a small trick that makes a game sound much more natural. Real cards never make exactly the same sound twice.

Topics covered in this lesson

  • Playing a sound with playsound
  • Picking a random sound file with random.choice()
  • Converting input to a number with int()
  • range() with a start and a stop
  • Pausing with time.sleep()
  • Off-by-one errors

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

Getting Ready

This program uses playsound. Install it with pip install playsound if you have not already. It plays shuffle.wav, deal1.wav, deal2.wav, and deal3.wav from the sounds folder. Run the program from the folder that holds the program and the sounds folder.

The Source Code for Sound Cards

Type this program and save it as sound_cards.py:

import random
import playsound as ps
import time

cards = ["2", "3", "4", "5", "6", "7", "8", "9", "10", "Jack", "Queen", "King", "Ace"]

clean_deck = []
for card in cards:
    for suit in ["Clubs", "Diamonds", "Hearts", "Spades"]:
        clean_deck.append([card, suit])

deck = clean_deck[:]  # copy a clean deck for use


random.shuffle(deck)  # Shuffle the deck.
ps.playsound("sounds/shuffle.wav")

count = int(input("How many cards do you want to deal? "))
for i in range(1, count + 1):
    sound = random.choice(["sounds/deal1.wav", "sounds/deal2.wav", "sounds/deal3.wav"])
    ps.playsound(sound)
    print(f"{' '.join(deck[i])}")
    time.sleep(0.5)

The first part, building the deck and copying it, is the same as in cards.py. If anything there is new to you, go back to that lesson first.

Shuffling with Sound

random.shuffle(deck)  # Shuffle the deck.
ps.playsound("sounds/shuffle.wav")

The deck is shuffled, and then the shuffle sound plays. The shuffle itself happens in a tiny fraction of a second, but the sound tells the player that it happened.

How Many Cards?

count = int(input("How many cards do you want to deal? "))

input() returns a string, such as "3". range() needs a number, so int() converts it. The prompt ends with a question mark and a space, so the player’s answer does not run into the question.

If the player types something that is not a number, int() causes an error and the program stops. Try typing three to hear it. A later exercise asks you to make this safer.

Dealing the Cards

for i in range(1, count + 1):
    sound = random.choice(["sounds/deal1.wav", "sounds/deal2.wav", "sounds/deal3.wav"])
    ps.playsound(sound)
    print(f"{' '.join(deck[i])}")
    time.sleep(0.5)

A Random Sound

The first line inside the loop picks one of three sound file names at random. random.choice() works on any list, including a list of file paths. Then ps.playsound(sound) plays the one it picked. Each card gets a slightly different sound.

range() with Two Arguments

Up to now you have given range() one number, and it has started at 0. You can also give it a start and a stop:

>>> list(range(1, 4))
[1, 2, 3]
>>> list(range(0, 4))
[0, 1, 2, 3]

The start number is included. The stop number is not. So range(1, count + 1) gives the numbers 1 through count. If the player asked for 3 cards, i will be 1, then 2, then 3.

A Pause Between Cards

time.sleep(0.5) waits half a second after each card. That gives the screen reader time to finish speaking the card before the next deal sound begins.

An Off-by-One Error

Here is a puzzle. The deck’s top card is deck[0]. Which cards does this loop deal?

i goes 1, 2, 3, so the loop deals deck[1], deck[2], and deck[3]. It never deals deck[0], the top card. And if the player asks for 52 cards, the loop tries to deal deck[52], which does not exist, because the last card is deck[51]. The program stops with an error:

IndexError: list index out of range

This kind of mistake is so common it has a name: an off-by-one error. It happens because people count from 1 and Python counts from 0. The range() was written to count from 1, like a person would, but the index needed to start at 0.

There are two easy fixes. You can loop with range(count), which gives 0 through count - 1. Or, even better for a card game, you can take cards off the deck as you deal them, with pop():

for _ in range(count):
    card = deck.pop()
    print(" ".join(card))

pop() removes the last item from a list and returns it. The card is gone from the deck, just like a real deal. You will see pop() in the Blackjack game.

Summary

You dealt cards with sound. You learned that:

  • random.choice() can pick a random sound file, so repeated events sound more natural.
  • range(start, stop) counts from start up to, but not including, stop.
  • time.sleep() gives the screen reader time to finish speaking.
  • An off-by-one error happens when counting from 1 and indexing from 0 get mixed up.
  • pop() removes and returns the last item of a list.
