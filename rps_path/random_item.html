Picking a Random Rock, Paper, or Scissors

Before you write a whole game of Rock, Paper, Scissors, you need the computer to make its move. In this short lesson, the computer picks rock, paper, or scissors at random and tells you what it picked.

Building a big program out of small, tested pieces is one of the most useful habits in programming. This program is the first piece.

Topics covered in this lesson

  • Docstrings
  • Lists
  • random.choice()
  • Storing a function’s result in a variable

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

Sample Runs

Random item choice Rock
Random item choice Scissors

The Source Code for Random Item

Type this program and save it as random_item.py:

"""Select a random item"""
import random

items = ["Rock", "Paper", "Scissors"]

random_item = random.choice(items)

print(f"Random item choice {random_item}")

How the Program Works

"""Select a random item"""

The docstring says what the program does.

import random

This imports the random module, which has functions for picking things by chance.

items = ["Rock", "Paper", "Scissors"]

This makes a list of the three moves and stores it in items.

random_item = random.choice(items)

random.choice() returns one item from the list, picked at random. Each item has the same chance. The program stores the result in random_item.

Storing the result in a variable is important. Once the computer has made its move, the program will need to use it more than once: to tell the player, and to decide who won. If you called random.choice() each time instead, you could get a different move each time.

Try this in the shell to hear the difference:

>>> import random
>>> items = ["Rock", "Paper", "Scissors"]
>>> move = random.choice(items)
>>> move
'Paper'
>>> move
'Paper'
>>> random.choice(items)
'Rock'
>>> random.choice(items)
'Paper'

The variable keeps the same value. Calling the function again picks again.

print(f"Random item choice {random_item}")

Finally, the program prints the move in an f-string.

Designing for the Ear

Random item choice Rock is understandable, but it sounds like a label, not a sentence. In a game you might say The computer chose rock. instead. A colon after choice would also help, because many screen readers pause a little at a colon.

Summary

You wrote the computer’s half of Rock, Paper, Scissors. You learned that:

  • Small programs can be pieces of a bigger one.
  • random.choice() picks one item from a list.
  • Store a random result in a variable if you need to use it more than once.
