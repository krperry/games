A Starting Point for Every Program

This program does nothing at all when you run it. That is on purpose. It is a template: a skeleton that you copy when you start a new program. It shows the shape that most Python programs have, with a main() function and a special if statement at the bottom.

In this lesson you will learn how to make your own functions and why so many Python programs end with the same two lines.

Topics covered in this lesson

  • Defining a function with def
  • The pass statement
  • Calling a function
  • The main() function
  • if __name__ == "__main__":

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

Sample Run

When you run python main.py, nothing is printed. The program starts, does nothing, and ends. The command prompt comes right back.

The Source Code for Main

Type this program and save it as main.py:

def main():
    pass


if __name__ == "__main__":
    main()

Defining a Function

def main():
    pass

You have been calling functions that come with Python, such as print() and input(). You can also make your own. Making a function is called defining it.

The def keyword starts a function definition. After it comes the function’s name, main, then a pair of parentheses, then a colon. The indented lines under it are the function’s body, the code that runs when the function is called.

Defining a function does not run it. It just teaches Python a new name. The body runs only when something calls the function.

pass

A function must have at least one line in its body. While you are still planning a program, you might not know what goes there yet. The pass statement means “do nothing.” It holds the place until you write real code.

The main() Function

There is nothing special about the name main to Python. You could name the function start or run_game. But programmers in many languages use main for the function that starts the program, so when someone reads your code, they know right where to look first.

Putting your program inside main() has another benefit. As your programs grow, you will split them into many functions. main() becomes a short summary that calls the others in order, like a table of contents.

The if name == “main”: Line

if __name__ == "__main__":
    main()

These two lines are at the bottom of a great many Python programs. Here is what they mean.

Listen carefully to the spelling. Each side of name and main has two underscores. Your screen reader may read this as “underline underline name underline underline.” Programmers often say “dunder name,” short for “double underscore name.”

__name__ is a variable that Python sets for you. When you run a file directly, by typing python main.py, Python sets __name__ to the string "__main__". When another program imports your file, so it can use your functions, Python sets __name__ to the file’s name instead, such as "main".

So the if statement means: “If this file is the one being run, call main().” If another program imports this file, main() is not called, and the other program can use your functions without starting your game.

You can see this for yourself. Add this line to the top of main.py:

print(f"__name__ is {__name__}")

Run python main.py and you will hear __name__ is __main__. Then start the interactive shell in the same folder and type import main. You will hear __name__ is main.

You will use this pattern in the Rock, Paper, Scissors game, in Tic Tac Toe, and in Hangman.

Using the Template

To start a new program from this template:

  1. Copy main.py and give the copy a new name.
  2. Add a docstring at the top that says what the program does.
  3. Add your import lines under the docstring.
  4. Replace pass with your program’s code, indented four spaces.
  5. As the program grows, move parts of it into their own functions, and call them from main().

For example:

"""Say hello to the player."""


def main():
    name = input("What is your name? ")
    print(f"Hello, {name}!")


if __name__ == "__main__":
    main()

Notice the two blank lines before and after the function. That is the usual Python style. It gives a clear break between functions, which is easy to find when you move through a file line by line.

Summary

This program does nothing, but it shows the shape of a good Python program. You learned that:

  • def defines a new function. The indented lines under it are its body.
  • Defining a function does not run it. Calling it does.
  • pass means “do nothing” and holds a place for code you have not written.
  • main() is the usual name for the function that starts a program.
  • if __name__ == "__main__": runs main() only when the file is run directly, not when it is imported.
