Printing a List of Choices

Games often read a list of choices to the player. In this lesson you will print every item in a list two ways: first by itself, and then with a number in front. Along the way you will see two ways to write a for loop over a list.

Topics covered in this lesson

  • Looping over the items in a list
  • Looping over the indexes of a list with range() and len()
  • Getting a list item by its index
  • Variable naming styles

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def main():, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson, code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

The Source Code for Print Choices

Type this program and save it as print_choices.py:

objectList = ["Rock", "Paper", "scissors"]

for item in objectList:
    print(item)


for i in range(len(objectList)):
    print(f"{i}. {objectList[i]}")

The List

objectList = ["Rock", "Paper", "scissors"]

This makes a list of three strings and stores it in the variable objectList.

A Note on Names

This variable name joins two words by making the second word start with a capital letter: objectList. This style is called camel case, because the capital letter sticks up like a camel’s hump. Other languages, such as JavaScript and Java, use it a lot.

Python programmers usually join words with an underscore instead, as in object_list. This style is called snake case. Both work. Python does not care. But using the same style everywhere makes your code easier to read, and underscores are often easier to hear with a screen reader, since the screen reader says “underline” or “underscore” between the words. The other programs in these lessons use snake case.

Also notice that "scissors" starts with a lowercase letter while the others are capitalized. Small differences like that are easy to miss in code but stand out to players.

Looping over Items

for item in objectList:
    print(item)

When you put a list after in in a for loop, the loop runs once for each item. Each time, the loop variable, item, holds the next item. The first time it is "Rock", then "Paper", then "scissors".

This is the simplest and most common way to go through a list. Use it whenever you only need the items themselves.

Looping over Indexes

for i in range(len(objectList)):
    print(f"{i}. {objectList[i]}")

This loop does something a little different. Let’s take the first line apart from the inside out.

len()

len() returns the length of a list, which is how many items are in it.

>>> objectList = ["Rock", "Paper", "scissors"]
>>> len(objectList)
3

It also works on strings, where it counts the characters:

>>> len("Rock")
4

range(len(…))

range(3) gives the numbers 0, 1, and 2. Those are exactly the indexes of a three-item list. So range(len(objectList)) gives you every index in the list, no matter how long the list is.

Getting an Item by Index

Inside the loop, i is an index. To get the item at that index, put the index in square brackets after the list:

>>> objectList[0]
'Rock'
>>> objectList[2]
'scissors'

So the f-string f"{i}. {objectList[i]}" prints the index, a period, a space, and the item.

Counting from One

The second loop prints 0. Rock. People expect a list to start at 1. Because the loop has the index in i, you can add 1 when you print it:

    print(f"{i + 1}. {objectList[i]}")

Now the list reads 1. Rock, 2. Paper, 3. scissors. That is much more natural to hear. It also matches what you would ask a player to type.

There is another way to get both the index and the item at once, called enumerate(). You will see it in the Pig dice game.

Summary

You printed a list two ways. You learned that:

  • for item in some_list: loops over the items.
  • len() returns the number of items in a list or characters in a string.
  • for i in range(len(some_list)): loops over the indexes.
  • some_list[i] gets the item at index i.
  • Add 1 to an index when you show it to people.
  • Python programmers usually name variables with underscores, like object_list.
