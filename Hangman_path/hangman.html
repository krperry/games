Designing and Writing an Accessible Hangman

In this lessonyou will design and then write a Hangman game. This game is longer than the games you have written so far, and it is also more fun. Because it is bigger, you will plan it first. Then you will write the code one function at a time.

This version of Hangman is built to be played completely by ear. It never draws pictures on the screen. Everything the player needs to know is said in plain words that a screen reader can read aloud. While you build it, you will learn how to design a program so that it works well for everyone who uses it.

A Note on Reading Code with a Screen Reader

Python uses indentation, the spaces at the start of a line, to show which lines belong together. A line that ends with a colon, such as while True: or def has_won(secret_word, guessed_letters):, starts a block. Every line in that block is indented four more spaces than the line with the colon.

Before you start, turn on indentation reporting in your screen reader or code editor so you hear how far each line is indented. In NVDA this setting is called “Line indentation reporting” and is under Document Formatting. JAWS and most code editors have a similar setting. Many blind programmers like to hear indentation as tones, but spoken numbers work too.

It also helps to set your screen reader to read all punctuation while you are working with code. Punctuation matters in Python. A missing colon, quote, or parenthesis is one of the most common errors.

In this lesson code you type into a file is shown in code blocks. Code you type into the interactive shell starts with three greater-than signs, >>>. That is the shell’s prompt. Do not type the prompt. Type only what comes after it. The lines with no prompt are what Python prints back.

How to Play Hangman

Hangman is a game for two players. One player thinks of a secret word and tells the other player how many letters it has. The second player guesses letters one at a time.

If the guessed letter is in the word, the first player shows where that letter goes. If the letter is not in the word, the guesser loses one of their chances. On paper, a missed guess is shown by drawing one part of a stick figure. In our game, we simply count the misses and say how many are left.

The guesser wins by finding every letter in the word before running out of wrong guesses. In our game, the computer is the player who thinks of the word, and you are the guesser. You can make six wrong guesses before you lose.

Designing for the Ear

Many Hangman programs draw the hanging man with keyboard characters, a style called ASCII art. A picture made of slashes, bars, and letters is easy to see but makes no sense when a screen reader reads it one symbol at a time. So before writing any code, decide how the game will give the player the same information in words.

Here are the design rules this game follows. Each one shapes a part of the code you will write.

  1. Say it in words, not pictures. Instead of a drawing, the game says Wrong guesses left: 4.
  2. Put spaces between letters. A screen reader may try to say _obb_ as one strange word. With spaces, _ o b b _, it reads each letter or blank on its own.
  3. Do not rely on one way of showing the same fact. Some screen readers do not speak underscores when the punctuation setting is low. So the game also says how many letters are still unknown.
  4. Let the player ask again. Speech goes by quickly. The player can type status at any time to hear the word, the guessed letters, and the guesses left again. Typing help repeats the commands.
  5. List guessed letters in alphabetical order with commas between them. b, e, o is easier to follow by ear than letters in the order they were guessed.
  6. Give a clear answer to every guess. The game says whether the letter is in the word and how many times it appears.
  7. Spell the answer. When the game ends without a win, the player hears the word and then its spelling, so an unusual word is not a mystery.
  8. Keep messages short and complete. Every message is a full sentence that makes sense on its own, because the player may only hear one line.

These rules make the game better for sighted players too. Clear words are easier for everyone.

Planning the Program with a Flowchart in Words

A flowchart is a plan that shows the steps of a program and the order in which they happen. Usually a flowchart is drawn as boxes connected by arrows. You can write the very same plan as a numbered outline. Each step is one box. “Go to step” is an arrow.

You do not have to make a plan before you code. But once you start programming, you will often think of things that must be added or changed. You may have to delete a lot of code you already wrote. Planning first saves that wasted work.

Building the Plan a Step at a Time

Start with the smallest plan possible: a start and an end.

  1. Start.
  2. End.

Now think about what happens when you play. First the computer thinks of a secret word. Then the player guesses a letter.

  1. Start.
  2. Think of a secret word.
  3. Ask the player to guess a letter.
  4. End.

But the game does not end after one guess. The program has to check whether the letter is in the word. There are two possibilities, so the plan branches, like a road that splits in two.

  • If the letter is in the word, check whether the player has found every letter and won.
  • If the letter is not in the word, count a wrong guess and check whether the player has run out of guesses and lost.

You do not need to check for a loss after a correct guess. A correct guess can never make the player lose. In the same way, a wrong guess can never make the player win.

The player does not guess only once. If they have not won or lost, they guess again. And when a game ends, the player is asked whether they want to play another game.

What if the player types the same letter twice, or types something that is not a letter? The game should not count that as a guess. It should explain the problem and ask again.

Finally, the player needs to know how they are doing. After every guess, the game should tell them the word with blanks, the letters they have guessed, and how many wrong guesses they have left. Our accessible design adds the commands help, status, and quit.

The Complete Plan

Here is the finished plan. Read it from step 1 and follow the “go to” instructions, just as you would follow arrows on a drawn flowchart.

  1. Start. Load the list of words and say welcome. Set the number of games won and lost to zero.
  2. Say “Starting a new game.” Pick a random secret word. Nothing has been guessed yet, and there have been no wrong guesses.
  3. Tell the player the status: how long the word is, the word with blanks, how many letters are unknown, which letters have been guessed, and how many wrong guesses are left.
  4. Ask the player for a guess.
    • If they type help, tell them the commands. Go to step 4.
    • If they type two or more characters, a character that is not a letter, or a letter they already guessed, explain the problem. Go to step 4.
    • If they type quit, tell them the word and its spelling. Go to step 8.
    • If they type status, go to step 3.
    • If they type a new letter, go to step 5.
  5. Add the letter to the guessed letters. Tell the player whether the letter is in the word and how many times.
    • If the letter is in the word, go to step 6.
    • If the letter is not in the word, add one wrong guess and go to step 7.
  6. If every letter in the word has been guessed, the player wins. Say so, add one to the games won, and go to step 8. Otherwise go to step 3.
  7. If the player has made six wrong guesses, the player loses. Say so, tell them the word and its spelling, add one to the games lost, and go to step 8. Otherwise go to step 3.
  8. Tell the player how many games they have won and lost.
    • If the player quit, go to step 10.
    • Otherwise, go to step 9.
  9. Ask whether they want to play again. If yes, go to step 2. If no, go to step 10.
  10. Say goodbye. End.

This plan maps out everything that can happen in the game. As you write the code, you will see each step turn into a function or a few lines of Python. When you design your own games, write a plan like this first. It will help you remember everything you need to code.

The Source Code for Hangman

Here is the whole program. Type it into your editor and save it as hangman.py. Then save the word list, new_words.txt, in the same folder. The program reads its words from that file. The file has one word on each line.

Do not worry if this looks like a lot. The rest of the lesson explains it one piece at a time. You may find it easier to type each function as you read about it, and run the whole program at the end.

When you type the code, pay close attention to indentation, colons, and quotation marks. If you get an error, Python tells you the line number. Go to that line and compare it carefully with the code here. Also check the line just before it, because a missing parenthesis or quote on one line often causes an error on the next.

"""Play a text-based game of Hangman in the terminal."""

import random

MAX_WRONG_GUESSES = 6


def load_words(file_name):
    """Read and return the words in the file at ``file_name``."""
    words = []
    word_file = open(file_name, "r")
    for word in word_file:
        words.append(word.strip())
    word_file.close()
    return words


def make_display_word(secret_word, guessed_letters):
    """Return the secret word with unguessed letters replaced by underscores.

    Separate the displayed characters with spaces so they can be read aloud
    one by one by a screen reader.
    """
    display = []
    for letter in secret_word:
        if letter.lower() in guessed_letters:
            display.append(letter)
        else:
            display.append("_")
    return " ".join(display)


def has_won(secret_word, guessed_letters):
    """Return whether every letter in ``secret_word`` has been guessed."""
    return count_blanks(secret_word, guessed_letters) == 0


def has_lost(wrong_guesses):
    """Return whether the number of wrong guesses has reached the limit."""
    return wrong_guesses >= MAX_WRONG_GUESSES


def spell_word(word):
    """Return ``word`` with spaces between its letters for spoken output."""
    return " ".join(word)


def show_score(wins, losses):
    """Print the totals for games won and lost."""
    print("Games won: " + str(wins) + ". Games lost: " + str(losses) + ".")


def count_blanks(secret_word, guessed_letters):
    """Return the number of letters in ``secret_word`` not yet guessed."""
    blanks = 0
    for letter in secret_word:
        if letter.lower() not in guessed_letters:
            blanks = blanks + 1
    return blanks


def get_guess(guessed_letters):
    """Prompt until the player enters a valid letter or a supported command.

    Return a new guessed letter, ``"quit"``, or ``"status"``. The ``help``
    command displays instructions and then prompts again.
    """
    while True:
        guess = input("Your guess: ")
        guess = guess.strip().lower()

        if guess == "help":
            show_help()
        elif guess in ["quit", "status"]:
            return guess
        elif len(guess) != 1:
            print("Please type just one letter.")
        elif not guess.isalpha():
            print("That is not a letter. Please type a letter from a to z.")
        elif guess in guessed_letters:
            print(
                "You already guessed " + guess + ". Try a different letter."
            )
        else:
            return guess


def check_guess(secret_word, guess):
    """Print whether ``guess`` occurs in ``secret_word``.

    Return the result, True or False.
    """
    count = secret_word.lower().count(guess)
    if count == 0:
        print("Sorry, there is no", guess, "in the word.")
        return False
    if count == 1:
        print("Yes! There is one", guess, "in the word.")
        return True
    print("Yes! There are", count, "of the letter", guess, "in the word.")
    return True


def show_welcome():
    """Print the welcome message and basic game instructions."""
    print("Welcome to Hangman.")
    print("I am thinking of a word. Guess it one letter at a time.")
    print("Each unknown letter is shown as an underscore.")
    print("You can make", MAX_WRONG_GUESSES, "wrong guesses before you lose.")
    print("Type the word help at any time to hear the commands.")
    print()


def show_help():
    """Print the available commands and how to use them."""
    print("Commands:")
    print("Type one letter and press Enter to guess it.")
    print("Type status to hear the word and your guesses again.")
    print("Type help to hear these commands.")
    print("Type quit to stop playing.")
    print()


def show_status(secret_word, guessed_letters, wrong_guesses):
    """Print the current word display and guessed letters.

    Also print how many wrong guesses remain.
    """
    print("The word has", len(secret_word), "letters.")
    print("Word:", make_display_word(secret_word, guessed_letters))
    print(
        count_blanks(secret_word, guessed_letters),
        "letters are still unknown.",
    )

    if len(guessed_letters) == 0:
        print("You have not guessed any letters yet.")
    else:
        sorted_letters = sorted(guessed_letters)
        print("Letters guessed so far:", ", ".join(sorted_letters))

    guesses_left = MAX_WRONG_GUESSES - wrong_guesses
    print("Wrong guesses left:", guesses_left)
    print()


def play_one_game(words):
    """Play one game using ``words``.

    Return ``"won"``, ``"lost"``, or ``"quit"``.
    """
    secret_word = random.choice(words)
    guessed_letters = []
    wrong_guesses = 0

    show_status(secret_word, guessed_letters, wrong_guesses)

    while True:
        guess = get_guess(guessed_letters)

        if guess == "quit":
            print(
                "The word was "
                + secret_word
                + ". It is spelled "
                + spell_word(secret_word)
                + "."
            )
            return "quit"

        if guess == "status":
            show_status(secret_word, guessed_letters, wrong_guesses)
            continue

        guessed_letters.append(guess)
        correct = check_guess(secret_word, guess)
        if not correct:
            wrong_guesses = wrong_guesses + 1

        if has_won(secret_word, guessed_letters):
            print("You win! The word was " + secret_word + ".")
            print(
                "You had",
                MAX_WRONG_GUESSES - wrong_guesses,
                "wrong guesses left.",
            )
            return "won"

        if has_lost(wrong_guesses):
            print("Out of guesses. You lose.")
            print(
                "The word was "
                + secret_word
                + ". It is spelled "
                + spell_word(secret_word)
                + "."
            )
            return "lost"

        show_status(secret_word, guessed_letters, wrong_guesses)


def ask_play_again():
    """Prompt until the player answers yes or no, then return their choice."""
    while True:
        answer = input("Do you want to play again? Type yes or no: ")
        answer = answer.strip().lower()
        if "yes".startswith(answer.lower()):
            return True
        if "no".startswith(answer.lower()):
            return False
        print("Please type yes or no.")


def main():
    """Load the word list and run games until the player chooses to stop."""
    words = load_words("new_words.txt")
    show_welcome()

    wins = 0
    losses = 0

    while True:
        print("Starting a new game.")
        result = play_one_game(words)

        if result == "won":
            wins = wins + 1
        elif result == "lost":
            losses = losses + 1

        show_score(wins, losses)

        if result == "quit":
            break
        if not ask_play_again():
            break
        print()

    print("Thanks for playing Hangman. Goodbye.")


main()

How the Program Is Organized

The program has four parts, from top to bottom:

  1. A docstring that describes the program, the import random line, and one constant, MAX_WRONG_GUESSES.
  2. Small helper functions that do one job each and print nothing: load_words(), make_display_word(), has_won(), has_lost(), spell_word(), and count_blanks(). The exception is show_score(), which prints the score.
  3. Functions that talk to the player: get_guess(), check_guess(), show_welcome(), show_help(), show_status(), play_one_game(), and ask_play_again().
  4. The main() function, which runs the whole thing, and the single line main() at the very bottom that calls it.

A good way to move around the file with a screen reader is to search for def, the word def followed by a space. Every function starts with it.

The rest of this lesson walks through the program in this order. Along the way, you will stop and try new ideas in the interactive shell.

Docstrings, Importing, and Constants

The very first line of the program is a string by itself:

"""Play a text-based game of Hangman in the terminal."""

A string in three double quotes can stretch across several lines. When a string like this is the first thing in a file or the first line of a function, it is called a docstring, short for documentation string. Python does not print it. It is there to tell people reading the code what the file or function does. Every function in this program has a docstring.

Some docstrings in this program put a name between two pairs of backquotes, like ``file_name``. That is just a common way of marking a name in documentation. It does not change how the program runs.

You can read a function’s docstring in the interactive shell with the help() function. For example, after you type a function into the shell, help(has_won) reads you its docstring.

Next comes the import:

import random

The game picks a random secret word. The random module has the code that does that, so the program imports it.

Then comes a variable with a name in all capital letters:

MAX_WRONG_GUESSES = 6

A name in all capitals is the Python way of saying “this is a constant.” A constant is a variable whose value should never change after it is set. Python does not stop you from changing it. The capital letters are a message to people reading the code.

Why use a constant instead of typing 6 everywhere? The number of allowed wrong guesses is used in four places: the welcome message, the status report, the win message, and the check for a loss. If you want to make the game easier and allow eight wrong guesses, you change one line and every part of the game agrees. If you had typed 6 in four places, you might change three of them and forget the fourth.

Lists

The game has to keep track of many words and many guessed letters. It does this with lists. A list is a value that holds other values in order. Try this in the interactive shell:

>>> animals = ["aardvark", "anteater", "antelope", "albert"]
>>> animals
['aardvark', 'anteater', 'antelope', 'albert']

A list starts with a left square bracket and ends with a right square bracket. Commas separate the values inside. The values in a list are called items. This list has four items, and each one is a string.

Without lists, you would need a separate variable for every animal. That would be impossible to manage with the more than 48,000 words in new_words.txt. A list can hold any number of items.

Getting Items by Index

Each item in a list has a number called its index. The first item is at index 0, the second at index 1, and so on. Put the index in square brackets after the list to get that item:

>>> animals[0]
'aardvark'
>>> animals[3]
'albert'

If you ask for an index that does not exist, Python stops with an IndexError:

>>> animals[9999]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: list index out of range

Our Hangman program does not use indexes directly, but it helps to know they are there. The random.choice() function, which you will meet soon, uses them for you.

The len() Function

The len() function tells you how many items are in a list. It also tells you how many characters are in a string:

>>> len(animals)
4
>>> len("lobby")
5

The game uses len() to tell the player how many letters the secret word has, to check whether the player typed exactly one character, and to see whether any letters have been guessed yet.

The in and not in Operators

The in operator checks whether a value is somewhere in a list. It gives back True or False:

>>> "antelope" in animals
True
>>> "ant" in animals
False

in also works on strings. It checks whether one string appears inside another:

>>> "obb" in "lobby"
True

The not in operator is the opposite. It gives True when the value is missing:

>>> "z" not in ["b", "e", "o"]
True

Hangman uses in and not in to ask, “Has the player already guessed this letter?”

Methods

A method is a function that belongs to a value. To call a method, type the value, a period, and then the method name with parentheses. Python has many methods for lists and strings. Here are the ones Hangman uses.

The append() List Method

The append() method adds an item to the end of a list:

>>> letters = []
>>> letters.append("e")
>>> letters
['e']
>>> letters.append("o")
>>> letters
['e', 'o']

Two square brackets with nothing between them make an empty list. The game starts each round with an empty list of guessed letters and appends each new guess to it.

append() changes the list it is called on. It does not make a new list. We say it changes the list in place.

The strip() and lower() String Methods

The strip() method gives back a copy of a string with spaces, tabs, and line endings removed from both ends. The middle is left alone:

>>> "  b  ".strip()
'b'

The lower() method gives back a copy of a string with every letter in lowercase. There is also an upper() method that does the opposite:

>>> "Hello World!".lower()
'hello world!'
>>> "Hello World!".upper()
'HELLO WORLD!'

You can chain methods, one after another. Python runs them from left to right. Each method works on the string the one before it gave back:

>>> "  B ".strip().lower()
'b'

String methods never change the original string. They give back a new one. So to keep the result, you store it in a variable, like this:

>>> guess = "  B "
>>> guess = guess.strip().lower()
>>> guess
'b'

Hangman uses these two methods on everything the player types. Then it does not matter if the player presses the space bar by accident or types a capital letter.

The isalpha() String Method

The isalpha() method gives True if every character in the string is a letter, and False if not:

>>> "b".isalpha()
True
>>> "7".isalpha()
False

The count() String Method

The count() method tells you how many times one string appears inside another:

>>> "lobby".count("b")
2
>>> "lobby".count("z")
0

Hangman uses count() to tell the player how many times their letter appears in the word.

The startswith() String Method

The startswith() method gives True if a string begins with the string you pass to it:

>>> "yes".startswith("y")
True
>>> "yes".startswith("ye")
True
>>> "yes".startswith("n")
False

There is also an endswith() method that checks the end of a string.

The join() String Method

The join() method is a little different. You call it on the string you want to put between items, and you pass it the items:

>>> " ".join(["_", "o", "b", "b", "_"])
'_ o b b _'
>>> ", ".join(["b", "e", "o"])
'b, e, o'

A string is a sequence of characters, so you can also join the characters of a string:

>>> " ".join("lobby")
'l o b b y'

join() is the most important method for making this game accessible. It puts spaces between the letters of the word so a screen reader reads them one at a time. It puts commas between the guessed letters so they are easy to tell apart.

Reading the Word List from a File

The first function in the program reads the words from new_words.txt:

def load_words(file_name):
    """Read and return the words in the file at ``file_name``."""
    words = []
    word_file = open(file_name, "r")
    for word in word_file:
        words.append(word.strip())
    word_file.close()
    return words

The function takes one parameter, file_name, the name of the file to read. It starts with an empty list called words.

The open() function opens a file so the program can use it. Its second argument, "r", means “read.” The program will only read the file, not change it. open() gives back a file object, which is stored in word_file.

A for loop over a file object gives you one line of the file at a time. Each line still has the invisible line-ending character at the end, so word.strip() removes it before the word is appended to the list.

When the loop is done, word_file.close() closes the file. It is good manners to close a file when you are finished with it. Finally, the function returns the full list of words.

The file must be in the folder you run the program from. If Python says FileNotFoundError, check that new_words.txt is in the same folder as hangman.py and that you started the program from that folder.

Keeping words in a separate file has a big advantage. You can change the words without changing the code. Make a file of your own, with one word on each line, and the game will use it.

Showing the Word with Blanks

The next function builds the version of the secret word the player hears, with an underscore for each letter that has not been guessed:

def make_display_word(secret_word, guessed_letters):
    """Return the secret word with unguessed letters replaced by underscores.

    Separate the displayed characters with spaces so they can be read aloud
    one by one by a screen reader.
    """
    display = []
    for letter in secret_word:
        if letter.lower() in guessed_letters:
            display.append(letter)
        else:
            display.append("_")
    return " ".join(display)

It has two parameters. secret_word is the word the player is trying to guess. guessed_letters is the list of letters guessed so far.

A for loop over a string gives you one character at a time. For each letter in the secret word, the function asks whether that letter has been guessed. If it has, the real letter goes into the display list. If not, an underscore goes in instead.

Why letter.lower()? Some words in the word list start with a capital letter, such as names of people and places. The player’s guesses are always lowercase. To compare them fairly, the function makes a lowercase copy of each letter before checking it. Notice that it appends the original letter, so a capital letter still shows as a capital.

At the end, " ".join(display) turns the list into one string with a space between each item.

Let’s follow the function when the secret word is lobby and the guessed letters are ["e", "o", "b"]:

  1. l is not in the guessed letters, so _ is appended.
  2. o is in the guessed letters, so o is appended.
  3. b is in the guessed letters, so b is appended.
  4. The second b is also appended.
  5. y is not in the guessed letters, so _ is appended.

The list is now ["_", "o", "b", "b", "_"], and the function returns the string _ o b b _.

Counting Blanks, Winning, and Losing

The next few functions answer simple questions about the game. Each one does one job and returns the answer.

Counting the Unknown Letters

count_blanks() appears later in the file, but it is easiest to look at first, because has_won() uses it:

def count_blanks(secret_word, guessed_letters):
    """Return the number of letters in ``secret_word`` not yet guessed."""
    blanks = 0
    for letter in secret_word:
        if letter.lower() not in guessed_letters:
            blanks = blanks + 1
    return blanks

This works like make_display_word(), but instead of building a list, it counts. blanks starts at 0. Every time the loop finds a letter that has not been guessed, it adds 1. For lobby with e, o, and b guessed, the l and the y are unknown, so the function returns 2.

Each repeated letter counts on its own. Lobby has two b’s, so before b is guessed, it adds 2 to the count.

The game tells the player this number after every guess. It is the second way of showing the same fact, in case the player’s screen reader does not speak the underscores.

Checking for a Win

def has_won(secret_word, guessed_letters):
    """Return whether every letter in ``secret_word`` has been guessed."""
    return count_blanks(secret_word, guessed_letters) == 0

The player has won when there are no blanks left. This function calls count_blanks() and compares the answer with 0. The comparison == 0 gives True or False, and the function returns that value.

This is a function calling another function. Notice that has_won() is written above count_blanks() in the file. That is fine. Python only needs count_blanks() to exist by the time has_won() actually runs, and nothing runs until the last line of the file calls main().

Why not just check whether the guessed letters equal the secret word? The player may guess the letters in any order, and guess wrong letters too. For lobby, the guessed letters might be e, o, b, t, l, y. That list is nothing like the word lobby, yet the player has found every letter. Counting blanks gives the right answer every time.

Checking for a Loss

def has_lost(wrong_guesses):
    """Return whether the number of wrong guesses has reached the limit."""
    return wrong_guesses >= MAX_WRONG_GUESSES

The >= operator means “greater than or equal to.” The player has lost once the number of wrong guesses reaches the limit. This function reads the constant MAX_WRONG_GUESSES. Functions can read variables that are set outside of any function.

Spelling a Word

def spell_word(word):
    """Return ``word`` with spaces between its letters for spoken output."""
    return " ".join(word)

This is one line, but it is an important accessibility feature. When the game ends without a win, the player hears the word spoken as a word and then hears it spelled, l o b b y. A screen reader might say an unusual word in a way that is hard to recognize. The spelling removes any doubt.

Showing the Score

def show_score(wins, losses):
    """Print the totals for games won and lost."""
    print("Games won: " + str(wins) + ". Games lost: " + str(losses) + ".")

The + operator joins strings together, but it cannot join a string and a number. The str() function turns the numbers into strings first. If wins is 1 and losses is 0, this prints Games won: 1. Games lost: 0.

Getting the Player’s Guess

get_guess() asks the player for a guess. It does not give up until the player types something the game can use.

def get_guess(guessed_letters):
    """Prompt until the player enters a valid letter or a supported command.

    Return a new guessed letter, ``"quit"``, or ``"status"``. The ``help``
    command displays instructions and then prompts again.
    """
    while True:
        guess = input("Your guess: ")
        guess = guess.strip().lower()

        if guess == "help":
            show_help()
        elif guess in ["quit", "status"]:
            return guess
        elif len(guess) != 1:
            print("Please type just one letter.")
        elif not guess.isalpha():
            print("That is not a letter. Please type a letter from a to z.")
        elif guess in guessed_letters:
            print(
                "You already guessed " + guess + ". Try a different letter."
            )
        else:
            return guess

A Prompt the Player Can Hear

input("Your guess: ") prints the words Your guess: and waits for the player to type something and press Enter. Putting the prompt inside input() keeps the prompt and the answer on the same line. A screen reader user who reviews the screen later hears Your guess: b on one line, which makes clear what they typed and why.

Next, guess.strip().lower() removes any extra spaces and makes the guess lowercase. Now B, b, and b with spaces around it all become b.

Leaving a while True Loop

The loop is while True:. True is always true, so this loop never ends on its own. The only way out is a return statement, which leaves not just the loop but the whole function, handing a value back to whoever called it.

That is exactly what we want. The function keeps asking until the guess is good, and then returns it.

elif Statements

The checks inside the loop use elif, which is short for “else if.” An if statement with elif parts says, “If this is true, do this. Or else, if this next thing is true, do that. Or else, if none of them is true, do this last thing.”

Here is a smaller example. Try it with different values of cat_name:

if cat_name == "Fuzzball":
    print("Your cat is fuzzy.")
elif cat_name == "Spots":
    print("Your cat is spotted.")
else:
    print("Your cat is not fuzzy or spotted.")

Python checks each condition from the top down. As soon as one is true, it runs that block and skips all the rest. So one, and only one, of the blocks runs. You can have as many elif parts as you want, and the else part at the end is optional.

The Order of the Checks Matters

Here are the checks in get_guess(), from top to bottom:

  1. If the guess is help, call show_help() to read the commands. The loop then goes around and asks again.
  2. If the guess is quit or status, return it. guess in ["quit", "status"] is a short way of asking whether the guess is either of those two words.
  3. If the guess is not exactly one character long, say Please type just one letter. The operator != means “is not equal to.”
  4. If the guess is not a letter, say so. The not operator flips True to False and False to True. So not guess.isalpha() is true when the guess is not a letter.
  5. If the letter has already been guessed, remind the player.
  6. If none of those problems happened, return the letter.

Why are the commands checked first? Because help, quit, and status are longer than one letter. If the length check came first, typing help would get the answer Please type just one letter. and the player could never use the command.

Every message tells the player what went wrong and what to do instead. Please type just one letter. is more helpful than Invalid input., especially when it is the only line the player hears.

Checking a Guess

Once the player has typed a good letter, check_guess() tells them whether it is in the word:

def check_guess(secret_word, guess):
    """Print whether ``guess`` occurs in ``secret_word``.

    Return the result, True or False.
    """
    count = secret_word.lower().count(guess)
    if count == 0:
        print("Sorry, there is no", guess, "in the word.")
        return False
    if count == 1:
        print("Yes! There is one", guess, "in the word.")
        return True
    print("Yes! There are", count, "of the letter", guess, "in the word.")
    return True

First it makes a lowercase copy of the secret word and counts how many times the guess appears in it. Then there are three cases:

  • The count is 0. The letter is not there. The function says so and returns False.
  • The count is 1. The function says there is one and returns True.
  • Otherwise, the count is 2 or more. The function says how many and returns True.

This function does two jobs. It tells the player the result, and it returns True or False so the rest of the game knows whether to count a wrong guess.

Notice there is no elif or else here. It is not needed, because a return statement ends the function. If the count is 0, the function returns right away, and the lines below it never run. The last two lines only run if neither if was true.

Printing Several Values at Once

These print() calls pass several values separated by commas:

print("Yes! There are", count, "of the letter", guess, "in the word.")

When you give print() several values, it prints them all on one line and puts a space between each one. It also turns numbers into text for you, so there is no need for str(). If count is 2 and guess is b, this prints Yes! There are 2 of the letter b in the word.

Compare this with show_score(), which uses + and str(). Both ways work. With +, you control every space yourself. With commas, print() adds the spaces for you. That is why show_score() can put a period right after a number, as in Games lost: 0., but the comma style always puts a space there.

Talking to the Player

Three functions print information for the player.

The Welcome Message and the Help Command

def show_welcome():
    """Print the welcome message and basic game instructions."""
    print("Welcome to Hangman.")
    print("I am thinking of a word. Guess it one letter at a time.")
    print("Each unknown letter is shown as an underscore.")
    print("You can make", MAX_WRONG_GUESSES, "wrong guesses before you lose.")
    print("Type the word help at any time to hear the commands.")
    print()


def show_help():
    """Print the available commands and how to use them."""
    print("Commands:")
    print("Type one letter and press Enter to guess it.")
    print("Type status to hear the word and your guesses again.")
    print("Type help to hear these commands.")
    print("Type quit to stop playing.")
    print()

These functions only print. Each message is a complete sentence. The welcome message explains what an underscore means, because that is the one symbol in the game the player has to understand. It also tells the player that help exists, so they never feel stuck.

Calling print() with nothing between the parentheses prints an empty line. The empty line separates one group of messages from the next. Many screen readers say “blank” for an empty line, which tells the player that a group has ended.

The Status Report

def show_status(secret_word, guessed_letters, wrong_guesses):
    """Print the current word display and guessed letters.

    Also print how many wrong guesses remain.
    """
    print("The word has", len(secret_word), "letters.")
    print("Word:", make_display_word(secret_word, guessed_letters))
    print(
        count_blanks(secret_word, guessed_letters),
        "letters are still unknown.",
    )

    if len(guessed_letters) == 0:
        print("You have not guessed any letters yet.")
    else:
        sorted_letters = sorted(guessed_letters)
        print("Letters guessed so far:", ", ".join(sorted_letters))

    guesses_left = MAX_WRONG_GUESSES - wrong_guesses
    print("Wrong guesses left:", guesses_left)
    print()

This function replaces the hanging man picture. It tells the player everything a sighted player would get from looking at the drawing and the blanks:

  1. How many letters the word has.
  2. The word itself, with underscores for unknown letters and spaces between them. This calls make_display_word().
  3. How many letters are still unknown. This calls count_blanks().
  4. The letters guessed so far.
  5. How many wrong guesses are left.

Look at step 4. If no letters have been guessed, the list is empty and len(guessed_letters) is 0. Instead of printing an empty line after Letters guessed so far:, which would be confusing to hear, the game says You have not guessed any letters yet.

Otherwise, the built-in sorted() function makes a new list with the items in alphabetical order. The original list is not changed. Try it:

>>> sorted(["o", "e", "b"])
['b', 'e', 'o']

Then ", ".join() puts a comma and a space between the letters. A screen reader reads b, e, o with a short pause at each comma.

Finally, the number of wrong guesses left is the limit minus the wrong guesses so far. Telling the player how many are left, instead of how many they have used, answers the question they really care about: how close am I to losing?

The game calls this function at the start of each round, after every guess, and whenever the player types status.

Playing One Game

play_one_game() is the heart of the program. It follows steps 2 through 7 of the plan. It plays a single game and returns a string that says how the game ended: "won", "lost", or "quit".

def play_one_game(words):
    """Play one game using ``words``.

    Return ``"won"``, ``"lost"``, or ``"quit"``.
    """
    secret_word = random.choice(words)
    guessed_letters = []
    wrong_guesses = 0

    show_status(secret_word, guessed_letters, wrong_guesses)

    while True:
        guess = get_guess(guessed_letters)

        if guess == "quit":
            print(
                "The word was "
                + secret_word
                + ". It is spelled "
                + spell_word(secret_word)
                + "."
            )
            return "quit"

        if guess == "status":
            show_status(secret_word, guessed_letters, wrong_guesses)
            continue

        guessed_letters.append(guess)
        correct = check_guess(secret_word, guess)
        if not correct:
            wrong_guesses = wrong_guesses + 1

        if has_won(secret_word, guessed_letters):
            print("You win! The word was " + secret_word + ".")
            print(
                "You had",
                MAX_WRONG_GUESSES - wrong_guesses,
                "wrong guesses left.",
            )
            return "won"

        if has_lost(wrong_guesses):
            print("Out of guesses. You lose.")
            print(
                "The word was "
                + secret_word
                + ". It is spelled "
                + spell_word(secret_word)
                + "."
            )
            return "lost"

        show_status(secret_word, guessed_letters, wrong_guesses)

Setting Up a New Game

    guessed_letters = []
    wrong_guesses = 0

random.choice() takes a list and returns one item from it, picked at random. Try it in the shell a few times:

>>> import random
>>> random.choice(["apple", "orange", "grape"])
'grape'
>>> random.choice(["apple", "orange", "grape"])
'apple'

You will probably get different answers, because they are random.

The game also starts with an empty list of guessed letters and zero wrong guesses. These three variables are created inside the function, so they are local variables. Every time play_one_game() is called, it gets a fresh set. That is how each new game starts clean.

Then the function calls show_status() so the player hears how long the word is before their first guess.

The Guessing Loop

The rest of the function is a while True: loop. Each time around the loop is one turn. The loop ends only when a return statement runs: when the player quits, wins, or loses.

Each turn starts by calling get_guess(), passing it the list of letters already guessed. Remember, get_guess() only returns a new letter, "quit", or "status". It handles everything else itself.

Quitting

If the guess is "quit", the game tells the player the word and its spelling and returns "quit".

The print() call here is long, so it is split across several lines. Python allows this because the lines are inside the parentheses of print(). Python knows the statement is not finished until the closing parenthesis. Each line starts with a + sign, which makes it easy to hear that each piece is joined to the one before. If the word is lobby, this prints The word was lobby. It is spelled l o b b y.

Status and the continue Statement

        if guess == "status":
            show_status(secret_word, guessed_letters, wrong_guesses)
            continue

If the player typed status, the game reads the status again. Then the continue statement jumps straight back to the top of the loop, skipping everything below it. The game asks for another guess without counting status as a guess.

Recording the Guess

        guessed_letters.append(guess)
        correct = check_guess(secret_word, guess)
        if not correct:
            wrong_guesses = wrong_guesses + 1

If the program gets this far, the guess is a new letter. It is added to the list of guessed letters. Then check_guess() tells the player whether the letter is in the word and returns True or False, which is stored in correct.

If the guess was not correct, one more wrong guess is counted. Notice that every letter, right or wrong, goes into guessed_letters. That one list is all the game needs to know which blanks to fill in and which letters the player cannot guess again.

Winning, Losing, or Going Around Again

            print("You win! The word was " + secret_word + ".")
            print(
                "You had",
                MAX_WRONG_GUESSES - wrong_guesses,
                "wrong guesses left.",
            )
            return "won"

            print("Out of guesses. You lose.")
            ...
            return "lost"

        show_status(secret_word, guessed_letters, wrong_guesses)

The three dots in this short version stand for the long print() call that tells the player the word and its spelling.

After each guess, the game checks for a win and then for a loss. Each check calls one of the small helper functions you wrote earlier. Because those functions have clear names, these lines read almost like English: “if has won,” “if has lost.”

If the player has won, the game says so and returns "won". If they have lost, it tells them the word and its spelling and returns "lost".

If neither happened, the game reads the status and the loop goes around for another turn.

Why Return a String?

play_one_game() does not keep score itself. It reports what happened and lets its caller decide what to do about it. Returning a short string, like "won", is a simple way to do that. This keeps each function focused on one job.

Asking to Play Again

def ask_play_again():
    """Prompt until the player answers yes or no, then return their choice."""
    while True:
        answer = input("Do you want to play again? Type yes or no: ")
        answer = answer.strip().lower()
        if "yes".startswith(answer.lower()):
            return True
        if "no".startswith(answer.lower()):
            return False
        print("Please type yes or no.")

This is another while True: loop that keeps asking until it gets a good answer. The prompt tells the player exactly what to type.

The checks use startswith() in a clever, backward way. Instead of asking whether the answer starts with y, it asks whether the word yes starts with the answer. So y, ye, and yes all count as yes. In the same way, n and no count as no. A word like maybe is neither, so the game says Please type yes or no. and asks again.

The answer has already been made lowercase on the line before, so the extra .lower() inside each check does not change anything. It is harmless.

What happens if the player presses Enter without typing anything? Then answer is an empty string, and every string starts with the empty string. Try it:

>>> "yes".startswith("")
True

So pressing Enter alone means yes, and a new game starts. This is a good example of why you should test what happens when a player types nothing. You will look at this again in the exercises.

The main() Function

main() follows the outer part of the plan: steps 1, 8, 9, and 10.

def main():
    """Load the word list and run games until the player chooses to stop."""
    words = load_words("new_words.txt")
    show_welcome()

    wins = 0
    losses = 0

    while True:
        print("Starting a new game.")
        result = play_one_game(words)

        if result == "won":
            wins = wins + 1
        elif result == "lost":
            losses = losses + 1

        show_score(wins, losses)

        if result == "quit":
            break
        if not ask_play_again():
            break
        print()

    print("Thanks for playing Hangman. Goodbye.")

First it loads the words, says welcome, and sets the score to zero. The words are loaded only once, before the loop, because reading a file of 48,000 words takes a moment and the words never change.

Each time around the loop is one whole game. main() stores the string returned by play_one_game() in result. If the result is "won", it adds one to wins. If it is "lost", it adds one to losses. If the player quit, neither number changes. Then it reports the score.

Leaving the Loop with break

The break statement leaves a loop right away. Unlike return, it does not leave the function. The program carries on with the first line after the loop, which here says goodbye.

There are two ways out of this loop:

  • If the player typed quit, the game breaks out of the loop without asking whether to play again. The player already said they want to stop.
  • If ask_play_again() returns False, then not ask_play_again() is True, and the game breaks out of the loop.

Notice that ask_play_again() is called inside the if condition itself. The question is asked, the answer comes back, and the if uses it, all on one line.

If the player wants another game, print() prints an empty line to separate the games, and the loop goes around again.

Calling main()

The very last line of the program is:

main()

Everything above it is a function definition. Defining a function does not run it. It only teaches Python what the function means. This one line is what actually starts the game. If you leave it out, the program runs, defines all the functions, and then ends without doing anything.

Putting the main part of a program in a function named main() is a common habit. It makes the start of the program easy to find. Search for def main and you are there.

Review of the Hangman Functions

Here is every function in the program and the job it does.

  • load_words(file_name) reads the file and returns a list of words.
  • make_display_word(secret_word, guessed_letters) returns the word with underscores for unknown letters and spaces between characters.
  • has_won(secret_word, guessed_letters) returns True if no blanks are left.
  • has_lost(wrong_guesses) returns True if the player has used all their wrong guesses.
  • spell_word(word) returns the word with spaces between its letters.
  • show_score(wins, losses) prints the number of games won and lost.
  • count_blanks(secret_word, guessed_letters) returns how many letters are still unknown.
  • get_guess(guessed_letters) asks until it gets a new letter, "quit", or "status", and returns it. It handles help itself.
  • check_guess(secret_word, guess) says whether the letter is in the word and how many times, and returns True or False.
  • show_welcome() prints the welcome and the basic rules.
  • show_help() prints the commands.
  • show_status(secret_word, guessed_letters, wrong_guesses) prints everything the player needs to know about the current game.
  • play_one_game(words) plays one game and returns "won", "lost", or "quit".
  • ask_play_again() returns True for yes and False for no.
  • main() runs games, keeps score, and says goodbye.

Look back at the plan. Each step in it became one of these functions, or a few lines inside play_one_game() or main(). That is what a good plan does for you.

Summary

Hangman is the biggest game you have written so far. You planned it first, with a flowchart written as a numbered outline, and then turned each step into code.

You also designed it to be heard instead of seen. You replaced pictures with words, put spaces between letters, gave the same fact in more than one way, let the player hear the status again, and spelled the answer. These choices are not extras added at the end. They shaped the code from the start.

Along the way, you learned these Python ideas:

  • Lists hold many values in order. append() adds to a list, in and not in check what is in it, len() counts it, and sorted() returns a sorted copy.
  • Methods are functions attached to a value. Strings have strip(), lower(), upper(), isalpha(), count(), startswith(), endswith(), and join().
  • open() opens a file, a for loop reads it a line at a time, and close() closes it.
  • random.choice() picks a random item from a list.
  • elif lets you check several conditions in a row. Only one block runs.
  • A while True: loop runs until a return or break statement ends it. continue jumps back to the top of the loop.
  • Constants are written in capital letters and should not change.
  • Docstrings explain what a file or function does.
  • Small functions with clear names make a big program easy to read.
